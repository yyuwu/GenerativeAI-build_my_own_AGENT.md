# 間接證明法 (Indirect Proof, IP / 歸謬法)

**間接證明法 (IP)**，又稱**反證法**或**歸謬法 (Reductio ad Absurdum)**，是邏輯與哲學論辯中最古老而強大的證明策略。

---

## 1. 核心理念與數學原理

演繹論證具有保真性（不可能從真前提推導出假結論）。因此：
- 若欲證明目標語句 $P$：
  1. **假設其否定為真 (AP)**：假定 $\neg P$（若待證為 $\neg P$，則假定 $P$）。
  2. **在該假設下推導出矛盾式**：導出形式為 $Q \land \neg Q$（或 $\bot$）的矛盾語句。
  3. **解除假設**：矛盾不可能為真，而原已知前提皆假定為真，故產生矛盾的唯一原因必然是暫時假設了 $\neg P$。因此消去假設，斷定 $P$ 為真！

---

## 2. 標準格式示範

```markdown
前提：
1. A -> B                      (前提)
2. B -> C                      (前提)
3. A                           (前提)  /∴ C

證明步驟：
4. | ~C                        (AP，假設結論為假，求證矛盾)
5. | A -> C                    (1, 2 HS)
6. | C                         (3, 5 MP)
7. | C · ~C                    (4, 6 Conj，導出矛盾！)
8. C                           (4-7 IP，解除假設)
Q.E.D.
```

---

## 3. 爆炸原理與 CP/IP 互導定理

### 3.1 爆炸原理 (Principle of Explosion: Ex Falso Quodlibet)
在經典邏輯中，**從矛盾句可以合法推導出任何任意語句**：
$$B \land \neg B \vdash X$$
推導過程只需四步：
1. $B \land \neg B$
2. $B$ (1 Simp)
3. $B \lor X$ (2 Add)
4. $\neg B$ (1 Simp)
5. $X$ (3, 4 DS)

### 3.2 IP 與 CP 互為導出規則
- 利用上述爆炸原理與 CP 規則，可以完全導出 IP 規則；反之，利用 IP 亦可完全導出 CP。
- 因此在後設邏輯中，自然演繹系統只要在 18 條規則外加入 **CP 或 IP 兩者之一**，系統即滿足[[後設邏輯_健全性與完備性|完備性]]。

---

## 4. 戰略建議

- **不要一開始就用 IP**：IP 往往需要將複合語句徹底打碎以尋找矛盾，有時會讓推導反而變長。
- **何時最適合使用 IP？**
  - 當**結論非常短**（例如單一原子語句 $A$ 或否定句 $\neg A$），直接推導缺乏著力點時，利用 IP 可以多獲得一個好用的假設短前提！
