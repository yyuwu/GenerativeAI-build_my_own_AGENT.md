# 後設邏輯：健全性 (Soundness) 與 完備性 (Completeness)

在邏輯學的高階視野中，**後設邏輯 (Metatheory)** 不在於推導具體題目，而在於以嚴格數學方式研究「邏輯推論系統本身」是否具備優良的理論性質。

---

## 1. 語意學 (Semantics) 與 語法學 (Syntax) 的雙軌對照

邏輯系統可以從兩條完全獨立的進路進行建構：

| 評估維度 | 語意學進路 (Semantics) | 語法學進路 (Syntax) | 兩者在語句邏輯中的等價關係 |
| :--- | :--- | :--- | :---: |
| **工具方法** | **真值表、賦值模型 (Valuation $V$)** | **自然演繹證明、推論規則** | 完美一致 |
| **無條件真語句** | **套套句 / 恆真句 ($\vDash \phi$)**：在每一種真值解釋上皆為真。 | **定理 ($\vdash \phi$)**：母需任何既定前提即可被演繹證明（零前提推導）。 | $\vDash \phi \iff \vdash \phi$ |
| **論證有效性** | **語意有效 ($\Gamma \vDash \phi$)**：沒有任何解釋會使得前提全為真而結論為假。 | **語法有效 ($\Gamma \vdash \phi$)**：能從前提集合構作有限步驟之證明導出結論。 | $\Gamma \vDash \phi \iff \Gamma \vdash \phi$ |
| **集合一致性** | **語意一致 / 可滿足 (Satisfiable)**：存在至少一種解釋使集合中所有語句同真。 | **語法一致**：不可能從該語句集合演繹推導出任何矛盾句（$q \land \neg q$）。 | 語意一致 $\iff$ 語法一致 |

---

## 2. 系統健全性 (Soundness of a Deductive System)

> **定義**：一個邏輯推論系統是**健全的 (Sound)**，若且唯若：
> $$\text{若 } \Gamma \vdash \phi \text{，則 } \Gamma \vDash \phi$$
> （特別地，若 $\vdash \phi$，則 $\vDash \phi$）

- **哲學意義**：**凡是能被系統證明出來的，保證必然是語意為真的！**
- 推論系統絕不會「說謊」，絕不可能從真前提推導出假結論。

---

## 3. 系統完備性 (Completeness of a Deductive System)

> **定義**：一個邏輯推論系統是**完備的 (Complete)**，若且唯若：
> $$\text{若 } \Gamma \vDash \phi \text{，則 } \Gamma \vdash \phi$$
> （特別地，若 $\vDash \phi$，則 $\vdash \phi$）

- **哲學意義**：**凡是在語意上普遍為真、邏輯有效的論證，推論系統都有能力將其證明出來！**
- 系統沒有任何「推論盲區」。
- **為什麼需要引進 CP 與 IP？**
  - 講義明確指出：**若僅有 18 條基本推論規則，系統是不完備的！**
  - 因為 18 條規則無法證明零前提定理（如 $A \lor \neg A$），也無法證明如 $A \rightarrow B \vdash A \rightarrow (A \land B)$。引進條件證法 (CP) 或間接證法 (IP) 正是為了使自然演繹系統達到**完備性**。
