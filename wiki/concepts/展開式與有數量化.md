# 展開式 (Expansion) 與 有數量化 (Numerical Quantifications)

量詞與等同符號（$=$）的結合，使邏輯系統能夠跳脫模糊的「所有」與「有些」，精確刻畫「至少 $n$ 個」、「至多 $n$ 個」與「恰好 $n$ 個」等高階數學與日常計數語句。

---

## 1. 有限論域的展開式 (Expansion)

直觀而言，在一個個體有限的論域中（例如 $\text{Domain} = \{a, b\}$）：
- **全稱量詞相當於連言 ($\land$)**：$(x)Fx \approx Fa \land Fb$
- **存在量詞相當於選言 ($\lor$)**：$(\exists x)Fx \approx Fa \lor Fb$

### 1.1 邏輯哲學限制
- 嚴格而言，展開式與量化句**並非邏輯等值**（因為展開式缺少了「本名單已窮盡宇宙所有事物」的形上學斷言）。
- 但展開式提供了量化語句的**最小真值條件**，是證明論證無效性時極其方便的工具。

---

## 2. 精確有數量化系統 (Numerical Quantifications)

在一般述詞邏輯中，$(\exists x)(\exists y)(Sx \land Sy)$ 僅代表「至少有一個學生」，因為 $x$ 與 $y$ 可能指涉同一個人。要精確計算數量，**必須引進等同符號 ($=$)**：

### 2.1 至少 (At Least)
- **至少一個**：$(\exists x)Sx$
- **至少兩個**：
  $$(\exists x)(\exists y)[Sx \land Sy \land (x \neq y)]$$
- **至少三個**：
  $$(\exists x)(\exists y)(\exists z)[Sx \land Sy \land Sz \land (x \neq y) \land (x \neq z) \land (y \neq z)]$$

### 2.2 至多 (At Most)
至多並不宣稱事物存在，而是宣稱「不存在超過該數量的事物」，故標準採用**全稱量詞**：
- **至多一個**：
  $$(x)[Sx \rightarrow (y)(Sy \rightarrow x = y)]$$
  （若 $x, y$ 都是學生，則他們必然是同一人；若無學生亦為真）。
- **至多兩個**：
  $$(x)(y)[(Sx \land Sy \land x \neq y) \rightarrow (z)(Sz \rightarrow (z = x \lor z = y))]$$

### 2.3 恰好 / 正好 (Exactly)
$$\text{恰好 } n \text{ 個} = \text{至少 } n \text{ 個} + \text{至多 } n \text{ 個}$$
- **恰好一個學生**：
  $$(\exists x)[Sx \land (y)(Sy \rightarrow x = y)]$$
  （存在一個學生 $x$，且任何身為學生的人都正是 $x$ 本人）。

---

## 3. 「只有 (Only)」與「除了…每個 (Everyone but)」

日常語言中的排除性語句可透過否定或不等於來表達：
- **「只有 George 及格」** / **「除了 George 以外全班都及格」**：
  $$\neg Pg \land (x)[(Sx \land x \neq g) \rightarrow Px]$$
  （斷言：George 本人不及格，且任何不是 George 的學生全都及格）。
