# 習題解析 Ch. 4：自然演繹法 18 條規則經典推導與後設邏輯

本篇精選第四章高頻題型，涵蓋輸出入律 (Exp)、分配律 (Dist)、二難推論 (CD) 的精妙搭配，以及表達完備性與析取範式 (DNF) 的後設邏輯證明。

---

## 一、 巧妙利用輸出入律 (Exp) 簡化證明 (Ex 4-8)

**題目**：$(A \land B) \rightarrow C,\ A \vdash B \rightarrow C$

### 方法一：運用 Exp（極簡 2 步法）
```markdown
1. (A · B) -> C                (前提)
2. A                           (前提)  /∴ B -> C
3. A -> (B -> C)               (1 Exp，解包複合前件)
4. B -> C                      (2, 3 MP)
Q.E.D.
```

### 方法二：運用 Impl, DeM, Assoc（古典展開 6 步法）
```markdown
1. (A · B) -> C                (前提)
2. A                           (前提)  /∴ B -> C
3. ~(A · B) v C                (1 Impl)
4. (~A v ~B) v C               (3 DeM)
5. ~A v (~B v C)               (4 Assoc，重整括弧)
6. ~~A                         (2 DN)
7. ~B v C                      (5, 6 DS)
8. B -> C                      (7 Impl)
Q.E.D.
```
> **戰略點評**：遇到前件為連言的條件句時，優先考慮使用 **Exp**，往往能省去大半的等值展開步驟。

---

## 二、 割離中間變元的分配律 (Dist) 應用 (Ex 4-7)

**題目**：$(B \land C) \lor D,\ \neg C \vdash D$

```markdown
1. (B · C) v D                 (前提)
2. ~C                          (前提)  /∴ D
3. D v (B · C)                 (1 Comm，將單項移至左側以利分配)
4. (D v B) · (D v C)           (3 Dist，展開為兩選言項之連言)
5. D v C                       (4 Simp，提取關鍵項，割離不要的 B)
6. D                           (2, 5 DS)
Q.E.D.
```

## 三、 後設邏輯精華：析取範式 (DNF) 與 表達完備性 (Ex 4-14)

### 1. 表達完備性定理 (Expressive Completeness)
算子集合 $\{\neg, \land, \lor\}$ 甚至 $\{\neg, \lor\}$ 具有表達完備性：任何真值表所定義的真值函應，都可以僅使用這組算子寫出合式公式。

### 2. 析取範式 (Disjunctive Normal Form, DNF) 建構法
對於任何真值表：
1. **鎖定所有輸出為真 ($T$) 的列**。
2. 對每一列，將輸入變元寫成連言項（若變元為 $T$ 則寫原句，若為 $F$ 則加否定號）。
3. 將所有真值列的連言項以選言符號（$\lor$）串接。
- **範例**：若真值表在第一列 $(T, T)$ 與第三列 $(F, T)$ 為真：
  $$\text{DNF Formula} = (p \land q) \lor (\neg p \land q)$$
這從數學上證明了一階語句邏輯語法的完整性與完備性。
