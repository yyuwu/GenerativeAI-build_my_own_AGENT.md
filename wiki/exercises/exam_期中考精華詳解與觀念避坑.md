# 期中考精華詳解與觀念避坑 (Midterm Exam Analysis)

本篇收錄「115上 邏輯期中考」的精華試題、核心是非題陷阱解析、禁用 CP/IP 的高階演繹證明以及零前提定理推導。

---

## 一、 十大是非題陷阱與反例剖析 (30%)

### 1. 反事實條件句 $\neq$ 實質條件句
- **命題**：「若太陽從西邊升起，我就請你吃飯。」可翻為實質條件句。
- **答案：F**
- **辨析**：該句語用語意為「絕不請吃飯」。若譯為實質條件句，假前項保證全句為真，造成語意嚴重扭曲。參閱[[實質條件句的哲學爭論與證成]]。

### 2. 語法結構 $\neq$ 語意等值
- **命題**：「小明不在家」的否定句是「小明在家」。
- **答案：F**
- **辨析**：「小明不在家」($\neg A$) 的語法否定句是「並非小明不在家」($\neg\neg A$)。雖然 $\neg\neg A \iff A$，但 $A$ 是肯定句，兩者語法結構不同。

### 3. 全假集合的一致性
- **命題**：若語句集中所有語句都同時為假，則此集合不一致。
- **答案：F**
- **辨析**：不一致是指「不可能同時為真」，但「可以同時為假」。例如 $\{\text{清華在巴黎},\ \text{台大在柏林}\}$ 全假，但集合顯然是一致的。

### 4. 前提一致且結論為假 $\neq$ 論證無效
- **命題**：論證前提一致且結論為假，則論證必無效。
- **答案：F**
- **辨析**：有效論證完全可以具備假前提與假結論（例如 $A \rightarrow B, A \vdash B$，當 $A$ 事實為假時，結論 $B$ 亦可為假，但形式為 MP 完全有效）。

### 5. 無效形式的取代實例可以有效
- **命題**：無效論證形式的取代實例都是無效論證。
- **答案：F**
- **辨析**：無效形式 $p, q \vdash r$ 的取代實例可以是 $A \rightarrow B, A \vdash B$（有效論證）。有效性只需具備「至少一個」有效形式即可。

### 6. 有效論證添加前提的單調性 (Monotonicity)
- **命題**：在有效論證的前提中添加新前提，新論證仍有效。
- **答案：T**
- **辨析**：古典演繹邏輯具備**單調性**。添加新前提絕不會破壞既有的保真推導鏈；語意上，不一致的反例集加入新語句依然是不一致的。

## 二、 禁用 CP / IP 的 18 條規則推導實戰 (30%)

### 題目：$C \lor D,\ C \rightarrow B,\ \neg C \rightarrow \neg D \vdash B$
```markdown
前提：
1. C v D                       (前提)
2. C -> B                      (前提)
3. ~C -> ~D                    (前提)  /∴ B

證明步驟：
4. D -> C                      (3 Contra，異質換位)
5. D -> B                      (2, 4 HS，串接為假言三段論)
6. B v B                       (1, 2, 5 CD，建設性兩難！)
7. B                           (6 Taut，重言化簡)
Q.E.D.
```

## 三、 零前提定理證明實戰 (15%)

### 證明定理：$\vdash ((P \rightarrow Q) \rightarrow Q) \rightarrow ((Q \rightarrow P) \rightarrow P)$
```markdown
證明步驟：
1. | (P -> Q) -> Q             (AP 1)  /∴ (Q -> P) -> P
2. | | Q -> P                  (AP 2)  /∴ P
3. | | (P -> Q) -> P           (1, 2 HS)
4. | | ~(~P v Q) v P           (3 Impl x2)
5. | | (P · ~Q) v P            (4 DeM, DN)
6. | | P v (P · ~Q)            (5 Comm)
7. | | (P v P) · (P v ~Q)      (6 Dist，利用分配律提取 P)
8. | | P v P                   (7 Simp)
9. | | P                       (8 Taut)
10. | (Q -> P) -> P            (2-9 CP)
11. ((P -> Q) -> Q) -> ((Q -> P) -> P) (1-10 CP)
Q.E.D.
```
