01 // THE CLASH OF INTUITIONS

形式規定 vs. 日常直覺的撕裂

核心提問：當前件為假時，「若 P 則 Q」為什麼被形式邏輯規定為「真 (True)」？
A日常生活中的荒謬感

「若有最大的偶數，則新竹是一座城市。」(F → T ≡ T)

「若有最大的偶數，則新竹是一種植物。」(F → F ≡ T)

常人直覺：前後毫無因果關係，純屬荒誕無稽之談，何以成真理？

B數學推導中的合理性

「若 5 是最大的偶數，則 7 不是偶數。」(F → T ≡ T)

「若 5 是最大的偶數，則 6 不是偶數。」(F → F ≡ T)

客觀推導：假定一個錯誤前提，確能保證推導出合理的推論結論。

形式極小語意：P → Q ≡ ¬ P ∨ Q ≡ ¬(P ∧ ¬ Q)，即「只要不出現前真而後假，即算為真」。衝突的本質不在於符號，而在於自然語言對「相干性 (Relevance)」的強烈預設。

02 // SYSTEM JUSTIFICATION

形式邏輯為何不能讓步？三大系統性理由

規定「前假則真」絕非任性，而是形式演繹體系賴以運轉的客觀基石：

1真值函應原則

複合句真值必須由成分句客觀真值唯一決定。若引入因果、時間或信念，演繹代換與機械驗證將徹底瓦解。

2保全核心推論規則

若第 2 列改為 T，則假言推理 (MP) 崩毀；若第 3、4 列改為 F，則否定前項謬誤反而在真值表上無法排除！

3自然演繹法約束

由附加律 (Add) Q ⊢ ¬ P ∨ Q 與實質蘊涵律 (Impl)，必然保證只要後件真，整個條件句必真。

邏輯體系的第一準則：保真性與演繹保守性。實質條件句是維持系統封閉自洽的最簡代數解。
03 // THE CLASSICAL PARADOXES

實質蘊涵的兩大經典悖論

悖論一假前項悖論 (False Antecedent)

¬ P ⊢ P → Q

拉丁格言：Ex falso quodlibet（偽妄之中，可推導出一切事物）。

  • 「若月球是起司做的，則地球是圓的。」(真)
  • 「若月球是起司做的，則地球是平的。」(真)

一個虛假事實，同時使得兩個相互矛盾的命題在形式上皆成立！

悖論二真後項悖論 (True Consequent)

Q ⊢ P → Q

形式意涵：一個真理，受到任何無稽之談的實質蘊涵。

  • 「若明天太陽下山，則 2 + 2 = 4。」(真)
  • 「若火星人正在統治地球，則 2 + 2 = 4。」(真)

前件完全喪失了作為後件「前提」或「理由」的功能。

04 // DEDUCTION THEOREM & CP

演繹定理的雙刃劍

演繹定理 (Deduction Theorem)： Γ, A ⊢ B ⟺ Γ ⊢ A → B

在自然演繹法的「條件證明法 (Conditional Proof, CP)」中，我們透過假定前件 A，若能有效推導出 B，即可封閉假設並輸出 A → B。

光明面：理性論證的普遍化

演繹定理保證了人類理性推論能從「特定情境的暫時假定」昇華為「普適客觀的條件規律」，是科學模型建構的核心思維。

陰暗面：無相干性的形式合法化

若結論 B 本身即為真理，根據系統完備性，任何無關假設 A 都能合法進入推導，形式化地催生了「無因果關聯的實質條件句」。

05 // NATURAL LANGUAGE RESISTANCE

自然語言的抗拒機制：充要混淆與反事實崩塌

1充要條件混淆與認知偏誤

日常語言中，人類極易將單向充分條件（If A then B）誤讀為雙向充要條件（Iff）。

在沃森選擇任務 (Wason Selection Task) 中，常人習慣性將條件句當作因果對稱體，導致大量犯下「肯定後項謬誤」與「否定前項謬誤」。

2反事實條件句的翻譯災難

日常修辭：「如果太陽從西邊升起，我就請你吃飯！」

說話者的真實語用意圖是強烈斷言「我絕不會請客」（後件假）。

但在實質條件句中，前件為假導致該句恆為真！形式系統直接將一句強烈否定認證為「客觀真理」。

核心啟示：日常語言中的「反事實條件句」絕不可草率套用經典語句邏輯的實質條件句！
06 // PHILOSOPHICAL REMEDIES

哲學家的修補路線：格萊斯與劉易斯

進路一格萊斯（H. P. Grice）語用學救援

核心主張：實質條件句的語意完全正確；人們感到違和，是違反了對話的「合作原則」。

量之準則 (Maxim of Quantity)：應提供最充分的資訊。若明知後件為真（如 2+2=4），就該直言；拐彎說「若下雨則 2+2=4」，在語用上誤導了他人。

格萊斯裁決：悖論語句不是假話，而是「極不適當的真話」。

進路二C. I. 劉易斯模態嚴格條件句

核心主張：真正的蘊涵必須具備必然性 (Necessity)，排除偶然性湊合：

P ⟹ Q ≡ □(P → Q) ≡ ¬◇(P ∧ ¬ Q)

在所有可能世界中，都不存在「P 為真而 Q 為假」的世界。這開闢了現代模態邏輯與可能世界語意學的嶄新航道。

07 // SYNTHESIS & INSIGHTS

形式工具的邊界與哲學啟示

形式符號系統的使命

追求外延性 (Extensionality)、演繹保真性與機械判定性；實質條件句是維持命題演算最簡潔、最強大的代數解。

自然語言溝通的使命

追求意圖傳遞、因果相干性、認知經濟性與語境適應；條件句承載著人類對世界規律的因果假定。

終極哲學反思：
實質蘊涵悖論不是符號系統的缺陷，而是人類為了獲得「確定性演算」所自覺付出的代價。
符號邏輯是理性論證的堅固骨架，但絕非鮮活自然語言的全部。
