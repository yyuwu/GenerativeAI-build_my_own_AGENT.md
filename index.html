一致性 (Consistency) 與 有效性檢測

在邏輯學中，「一致性」是針對一個陳述句集合 (A set of statements) 的核心語意性質，並且是檢驗論證形式有效性的一項強大工具。

1. 一致性與不一致性的定義

一致性並非描述單一語句，而是描述一群語句構成的集合：

  • 一致的 (Consistent)：
    • 一個陳述句集合是一致的，若且唯若：在邏輯上可能 (logically possible) 該集合中的所有語句同時為真。
  • 不一致的 (Inconsistent)：
    • 一個陳述句集合是不一致的，若且唯若：集合內部的成員之間存在矛盾（Contradiction），在邏輯上不可能所有語句在同一時間皆為真。
  • 形式決定：如同論證有效性一樣，集合的一致與否同樣由語句的邏輯形式決定。

1.1 經典範例

  • 符號範例（顯然不一致）：
{p ∧ q,\ ¬ p,\ ¬ q}

（若 p ∧ q 為真，則 p 必為真，但第二個語句斷定 p 為假，構成矛盾）

  • 哲學/歷史範例（甘迺迪道德悖反集合）：
    1. 約翰·甘迺迪（J.F. Kennedy）是一位具有崇高道德品格的人。
    2. 約翰·甘迺迪經常通姦出軌。
    3. 沒有任何經常通姦出軌的人具有崇高道德品格。 → 這三句話所構成的集合是邏輯上不一致的（三者不可能同時為真）。
  • 隱含不一致（理髮師悖論 Barber Paradox）：

    「理髮師哈利只給村裡所有不給自己刮鬍子的人刮鬍子。」
    提問：哈利給不給自己刮鬍子？若給自己刮，依定義他不應給自己刮；若不給自己刮，依定義他必須給自己刮。此集合內部隱含矛盾。

2. 一致性與有效性的深刻關聯 (The Fundamental Equivalence)

演繹論證的有效性與陳述句集合的不一致性，本質上互為一體兩面：

  1. 有效論證唯一排除的狀況：前提全部為真，但結論為假（即前提全真且「結論的否定」為真）。
  2. 不一致集合唯一排除的狀況：集合中所有的陳述全部同時為真。

核心等價定理：

論證是有效的 (Valid) ⟺ {所有前提} ∪ {¬結論} 所構成的集合是「不一致的 (Inconsistent)」

換言之：

An argument is valid if and only if it is inconsistent to say that all its premises are true and its conclusion is false.

3. 一致性檢測法 (Consistency Test for Validity)

藉由上述等價定理，我們可以把任何論證的有效性檢驗，轉換為集合的一致性檢測：

flowchart TD
    A["給定待檢驗論證：前提集合 P1, P2...Pn / 結論 C"] --> B["構造集合：{ P1, P2...Pn, ¬C }"]
    B --> C{"檢測集合內部是否可能同時為真？"}
    C -- "邏輯上可能同時為真 (一致 Consistent)" --> D["結論：原論證為【無效 (Invalid)】"]
    C -- "邏輯上不可能同時為真 (不一致 Inconsistent)" --> E["結論：原論證為【有效 (Valid)】"]

3.1 課堂經典檢測示範（死刑廢除論證）

  • 原論證：
    1. 如果死刑不比無期徒刑更有嚇阻作用，則死刑應該被廢除。(P → Q)
    2. 死刑不比無期徒刑更有嚇阻作用。(P) \therefore 3. 死刑應該被廢除。(Q)
  • 檢測步驟：
    • 將「結論的否定（¬ Q：死刑不應該被廢除）」加入前提集合：
{P → Q,\ P,\ ¬ Q}
  • 由前提 1 與前提 2 依MP可推得 Q。
  • Q 與 ¬ Q 形成直接矛盾（Q ∧ ¬ Q），邏輯上不可能同時成立。
  • 因此該集合是不一致的 (Inconsistent)。
  • 檢驗結果：原論證被確認為形式有效 (Valid)！

使用 (Use) 與 提及 (Mention)

在語言哲學與符號邏輯中，區分「使用一個符號」與「提及一個符號」是避免語意悖論與範疇混淆的核心原則。

1. 概念定義

  • 使用 (Use)：當我們使用一個字詞或語句時，我們的焦點在於該詞彙所指涉的客觀世界對象、事態或概念（Talk about the world）。
  • 提及 (Mention)：當我們提及一個字詞或語句時，我們是在談論該字詞符號本身（如其拼字、字元數、發音或語法屬性，Talk about the word）。在書寫上，必須使用引號 (Quotation marks) 將其框起。

1.1 經典範例對照

  • Use（使用）：

    "Paris is a city in France."（巴黎是法國的一個城市）
    → 談論的是地理上真實存在的巴黎城市。

  • Mention（提及）：

    " 'Paris' has five letters."（「巴黎」這個英文單字有五個字母）
    → 談論的是包含五個字母的單字符號本身，而非巴黎城市。

2. 對象語言 (Object Language) 與 後設語言 (Metalanguage)

「使用」與「提及」的區分直接對應到符號邏輯的語言層次：

  1. 對象語言 (Object Language)：我們正在研究、運算的底層符號系統。
    • 在本課程中，語句邏輯符號系統（包含 p, q, ∧, ∨, → 等）即為對象語言。
  2. 後設語言 (Metalanguage)：我們用來談論、解釋、證明對象語言的上一層語言。
    • 在本課程中，我們用以撰寫講義、解釋真值表的中文、英文或後設符號（如 ⊢, ⊨, wff）即屬於後設語言。

深刻洞見：真值表本身並不是用對象語言寫成的，而是後設語言的一種簡明表達工具。當我們說「語句 A 是真的」時，我們是在後設語言中談論語句本身，而非該語句所表述的事實。

個體 (Individuals)、述詞 (Predicates) 與 量詞 (Quantifiers)

一階述詞邏輯（First-Order Predicate Logic）突破了語句邏輯將句子視為黑盒子的局限，深入剖析語句內部的主詞—述詞結構與量化範疇。

1. 符號體系與語法要素

符號類別 標準記號 範例與意義 哲學功能
個體常元 (Individual Constants) a, b, c … t a: 蘇格拉底, c: 柯林頓 指涉論域中特定且具體的對象、事物或實體。
個體變元 (Individual Variables) u, v, w, x, y, z x, y 佔位符（Placeholders），代表論域中任意或未知的個體。
性質/述詞常元 (Predicates) 大寫 A, B, C … Hx: x 是人；Mx: x 會死 描述個體所具有的屬性 (Properties)。
關係述詞 (Relational Predicates) 多元述詞 Rxy, Bxyz Txy: x 比 y 高；Lxy: x 喜愛 y 描述兩個或多個個體之間的客觀關係。

2. 量詞 (Quantifiers) 與 作用域 (Scope)

述詞邏輯引入兩大核心量詞，用以陳述性質適用的個體範圍：

2.1 全稱量詞 (Universal Quantifier)

  • 記號：(x) 或 ∀ x
  • 讀法：「對所有的 x」、「對任意的 x」。
  • 標準句型：「所有人都是會死的」→ (x)(Hx → Mx)。
    • 重要警訊：全稱句標準搭配條件句 (→)；若寫成 (x)(Hx ∧ Mx)，則會變成荒謬的「宇宙間每樣東西都是會死的人」。

2.2 存在量詞 (Existential Quantifier)

  • 記號：(∃ x)
  • 讀法：「存在至少一個 x」、「對某些 x」。
  • 標準句型：「有些人是快樂的」→ (∃ x)(Px ∧ Hx)。
    • 重要警訊：存在句標準搭配連言 (∧)；若寫成 (∃ x)(Px → Hx)，只要存在任何非人的東西（前件為假），該句便空洞為真。

3. 自由變元 (Free) vs. 拘束變元 (Bound)

  • 拘束變元 (Bound Variable)：直接處於相應量詞控制範圍（作用域 Scope）之內的變元。例如在 (x)(Fx → Gx) 中，x 是拘束變元。
  • 自由變元 (Free Variable)：未被任何量詞控制的變元。例如在 Fx ∧ (y)Gy 中，前一個 x 是自由變元。
  • 命題判準：
    • 只有不含任何自由變元的合式公式，才是真正的「語句 (Sentence)」，才具有確定的真假值。
    • 含有自由變元的表達式是「命題函式 (Propositional Function)」或語句形式。

4. 論域 (Domain of Discourse)

  • 定義：量詞所涵蓋評估的事物範圍集合。
  • 論域相依性：
    • 若論域不加限制（全宇宙一切事物）：「人皆會死」必須寫為 (x)(Hx → Mx)。
    • 若論域明確限制為 Domain = {人類}，則可簡寫為 (x)Mx。

實質條件句的哲學爭論與證成 (Philosophical Justification of Material Implication)

實質條件句的哲學爭論與證成 (Material Implication)

在經典命題邏輯中，初學者最常感到困惑的定義是：當前件 P 為假時，實質條件句 P → Q 為什麼被規定為「真 (True)」？

一、 兩類日常直覺的對立

1. 內容不相干的語句（顯得荒謬反直覺）

  • (a)「如果新竹是一座城市，則沒有最大的偶數。」(前真後真 → T)
  • (b)「如果有最大的偶數，則新竹是一座城市。」(前假後真 → T)
  • (c)「如果有最大的偶數，則新竹是一種植物。」(前假後假 → T) 在日常對話中，若前後句毫無實質因果關聯，人們直覺會認為 (b) 與 (c) 是假話或無稽之談。

2. 內容相干的數學與邏輯語句（顯然為真）

  • (d)「如果沒有最大的偶數，則沒有最大的數。」(前真後真 → T)
  • (e)「如果 5 是最大的偶數，則 7 不是偶數。」(前假後真 → T)
  • (f)「如果 5 是最大的偶數，則 6 不是偶數。」(前假後假 → T) 在涉及客觀推導的脈絡下，幾乎所有人皆會同意 (e) 與 (f) 是完全正確的真命題。

二、 邏輯系統採納實質條件句的三大根本理由

哲學家與邏輯學家之所以堅持將「前假」的條件句全數定為真，並非任性規定，而是基於三大深刻的系統性考量：

1. 系統一致性 (Consistency with Truth-Functionality)

  • 真值函應原則 (Principle of Truth-Functionality) 要求：任何複合語句的真假值，必須且只能由其成分語句的真值唯一決定，不可依賴外部脈絡或實質因果。
  • 這是使真值表法與語法取代理論保持完美一致的數學基石。

2. 語意理論的簡單性 (Simplicity)

  • 若否認真值函應原則，主張 P → Q 在 P 假時「有時為真、有時為假」，則邏輯學必須被迫在語意理論中引進龐大而主觀的因果關聯、時間先後或信念強度模型。

3. 嚴格保全核心推論規則的有效性 (Preserving Modus Ponens)

若顛倒任何一列的真值定義，將導致日常直覺顯然有效的論證變成無效，或使荒謬的論證變成有效：

  • 若第 2 列 (T, F) 定為 T：P → Q (T),\ P (T) ⊢ Q (F) 將摧毀演繹邏輯的立足基石——肯定前項 (MP)！
  • 若第 3 列 (F, T) 定為 F：論證 P → Q (F),\ ¬ P (T) ⊢ ¬ Q (F) 將無法被判定為無效。
  • 若第 4 列 (F, F) 定為 F：論證 P → Q (F),\ ¬ P (T) ⊢ Q (F) 將無法被判定為無效。

三、 重要反思：反事實條件句 (Counterfactual Conditionals)

期中考經典陷阱題：「如果太陽從西邊升起來，我就請你吃飯。」能否恰當地翻譯為實質條件句？ 答案：不能！

  • 語用意義 (Pragmatics)：說話者真正的意圖是強烈斷言：「我絕不會請你吃飯（結論為假）」。
  • 形式翻譯的災難：若翻譯為實質條件句 S → T，由於「太陽從西邊升起」在現實中為假，依據邏輯真值表，整個條件句將自動變成真話，完全扭曲了說話者原本要表達的語意。
  • 結論：日常語言中的「反事實條件句」不可草率套用經典語句邏輯的實質條件句。

對當方陣 (Square of Opposition) 與 範恩圖 (Venn Diagrams)

西方傳統亞里斯多德邏輯與現代述詞邏輯皆以四大直言命題（Categorical Propositions）為核心基石。

1. 四大標準命題形式 (A, E, I, O)

代號 拉丁字根 命題類型 自然語言標準式 現代述詞邏輯符號化 集合論範恩圖定義
A Affirmo 全稱肯定 所有 A 都是 B (x)(Ax → Bx) A \setminus B = ∅（A 中非 B 處劃陰影）
E Nego 全稱否定 沒有 A 是 B（全不） (x)(Ax → ¬ Bx) A ∩ B = ∅（交集區域劃陰影）
I Affirmo 特稱肯定 有些 A 是 B (∃ x)(Ax ∧ Bx) A ∩ B ≠ ∅（交集區域打叉 ×）
O Nego 特稱否定 有些 A 不是 B (∃ x)(Ax ∧ ¬ Bx) A \setminus B ≠ ∅（A 扣除 B 處打叉 ×）

2. 現代對當方陣與矛盾關係

       A: (x)(Ax -> Bx)  -----------(反對關係*)----------  E: (x)(Ax -> ~Bx)
             \                                                    /
              \                                                  /
               \                  對角線為                      /
                \                 【矛盾關係】                 /
                 \             (Contradictories)             /
                  \                                         /
                   \                                       /
       I: (∃x)(Ax · Bx)  ----------(下反對關係*)---------  O: (∃x)(Ax · ~Bx)

核心矛盾定理 (對角線 QN)

  • A 與 O 相互矛盾：¬(x)(Ax → Bx) ⟺ (∃ x)(Ax ∧ ¬ Bx)
  • E 與 I 相互矛盾：¬(x)(Ax → ¬ Bx) ⟺ (∃ x)(Ax ∧ Bx)
  • 這組矛盾關係直接對應到現代邏輯中的量詞否定規則_QN。

3. 存在意涵的歷史大分水嶺 (Existential Import)

傳統邏輯與現代邏輯在對當方陣上的最大歧異，在於是否預設主詞集合非空：

  1. 亞里斯多德傳統邏輯（有存在意涵）：
    • 預設我們所討論的對象必然存在於現實世界中。
    • 若 A 命題為真，則自動可推導出 I 命題為真（差等關係 Subalternation）。
    • 若所論對象不存在（如獨角獸、飛天意麵神），整句話被視為無意義或假。
  2. 現代一階述詞邏輯（布爾進路，無存在意涵）：
    • 完全不預設主詞集合存在個體！
    • 全稱條件句 (x)(Ax → Bx) 在前件 Ax 為空集時，空洞為真 (Vacuously true)。
    • 因此：「所有獨角獸都有翅膀」在現代邏輯中是真話（因為世上沒有獨角獸）；且絕不能從「所有 A 是 B」直接推導出「存在有 A 是 B」！

展開式與有數量化 (Expansion & Numerical Quantifications)

展開式 (Expansion) 與 有數量化 (Numerical Quantifications)

量詞與等同符號（=）的結合，使邏輯系統能夠跳脫模糊的「所有」與「有些」，精確刻畫「至少 n 個」、「至多 n 個」與「恰好 n 個」等高階數學與日常計數語句。

1. 有限論域的展開式 (Expansion)

直觀而言，在一個個體有限的論域中（例如 Domain = {a, b}）：

  • 全稱量詞相當於連言 (∧)：(x)Fx \approx Fa ∧ Fb
  • 存在量詞相當於選言 (∨)：(∃ x)Fx \approx Fa ∨ Fb

1.1 邏輯哲學限制

  • 嚴格而言，展開式與量化句並非邏輯等值（因為展開式缺少了「本名單已窮盡宇宙所有事物」的形上學斷言）。
  • 但展開式提供了量化語句的最小真值條件，是證明論證無效性時極其方便的工具。

2. 精確有數量化系統 (Numerical Quantifications)

在一般述詞邏輯中，(∃ x)(∃ y)(Sx ∧ Sy) 僅代表「至少有一個學生」，因為 x 與 y 可能指涉同一個人。要精確計算數量，必須引進等同符號 (=)：

2.1 至少 (At Least)

  • 至少一個：(∃ x)Sx
  • 至少兩個：
(∃ x)(∃ y)[Sx ∧ Sy ∧ (x ≠ y)]
  • 至少三個：
(∃ x)(∃ y)(∃ z)[Sx ∧ Sy ∧ Sz ∧ (x ≠ y) ∧ (x ≠ z) ∧ (y ≠ z)]

2.2 至多 (At Most)

至多並不宣稱事物存在，而是宣稱「不存在超過該數量的事物」，故標準採用全稱量詞：

  • 至多一個：
(x)[Sx → (y)(Sy → x = y)]

（若 x, y 都是學生，則他們必然是同一人；若無學生亦為真）。

  • 至多兩個：
(x)(y)[(Sx ∧ Sy ∧ x ≠ y) → (z)(Sz → (z = x ∨ z = y))]

2.3 恰好 / 正好 (Exactly)

恰好 n 個 = 至少 n 個 + 至多 n 個
  • 恰好一個學生：
(∃ x)[Sx ∧ (y)(Sy → x = y)]

（存在一個學生 x，且任何身為學生的人都正是 x 本人）。

3. 「只有 (Only)」與「除了…每個 (Everyone but)」

日常語言中的排除性語句可透過否定或不等於來表達：

  • 「只有 George 及格」 / 「除了 George 以外全班都及格」：
¬ Pg ∧ (x)[(Sx ∧ x ≠ g) → Px]

（斷言：George 本人不及格，且任何不是 George 的學生全都及格）。

後設邏輯：健全性 (Soundness) 與 完備性 (Completeness)

在邏輯學的高階視野中，後設邏輯 (Metatheory) 不在於推導具體題目，而在於以嚴格數學方式研究「邏輯推論系統本身」是否具備優良的理論性質。

1. 語意學 (Semantics) 與 語法學 (Syntax) 的雙軌對照

邏輯系統可以從兩條完全獨立的進路進行建構：

評估維度 語意學進路 (Semantics) 語法學進路 (Syntax) 兩者在語句邏輯中的等價關係
工具方法 真值表、賦值模型 (Valuation V) 自然演繹證明、推論規則 完美一致
無條件真語句 套套句 / 恆真句 (⊨ ϕ)：在每一種真值解釋上皆為真。 定理 (⊢ ϕ)：母需任何既定前提即可被演繹證明（零前提推導）。 ⊨ ϕ ⟺ ⊢ ϕ
論證有效性 語意有效 (Γ ⊨ ϕ)：沒有任何解釋會使得前提全為真而結論為假。 語法有效 (Γ ⊢ ϕ)：能從前提集合構作有限步驟之證明導出結論。 Γ ⊨ ϕ ⟺ Γ ⊢ ϕ
集合一致性 語意一致 / 可滿足 (Satisfiable)：存在至少一種解釋使集合中所有語句同真。 語法一致：不可能從該語句集合演繹推導出任何矛盾句（q ∧ ¬ q）。 語意一致 ⟺ 語法一致

2. 系統健全性 (Soundness of a Deductive System)

定義：一個邏輯推論系統是健全的 (Sound)，若且唯若：

若 Γ ⊢ ϕ ，則 Γ ⊨ ϕ

（特別地，若 ⊢ ϕ，則 ⊨ ϕ）

  • 哲學意義：凡是能被系統證明出來的，保證必然是語意為真的！
  • 推論系統絕不會「說謊」，絕不可能從真前提推導出假結論。

3. 系統完備性 (Completeness of a Deductive System)

定義：一個邏輯推論系統是完備的 (Complete)，若且唯若：

若 Γ ⊨ ϕ ，則 Γ ⊢ ϕ

（特別地，若 ⊨ ϕ，則 ⊢ ϕ）

  • 哲學意義：凡是在語意上普遍為真、邏輯有效的論證，推論系統都有能力將其證明出來！
  • 系統沒有任何「推論盲區」。
  • 為什麼需要引進 CP 與 IP？
    • 講義明確指出：若僅有 18 條基本推論規則，系統是不完備的！
    • 因為 18 條規則無法證明零前提定理（如 A ∨ ¬ A），也無法證明如 A → B ⊢ A → (A ∧ B)。引進條件證法 (CP) 或間接證法 (IP) 正是為了使自然演繹系統達到完備性。

恆真句、矛盾句與適真句

#語意學#核心概念#語句分類
wiki/concepts/恆真句_矛盾句與適真句.md

恆真句 (Tautology)、矛盾句 (Contradiction) 與 適真句 (Contingent Sentence)

在語句邏輯語意學中，根據語句在所有可能真值賦值（Valuation）下的真假表現，可將所有合式語句劃分為三大類。

1. 三大類語句的定義與特徵

語句分類 定義標準 真值決定因素 符號與範例
恆真句 / 套套句 (Tautology) 在其真值表的所有列中真值皆為真 (Always True)。 純由其邏輯形式決定，與經驗世界無關。 p ∨ ¬ p；p → (q → p)；標記為 →p
矛盾句 (Contradiction) 在其真值表的所有列中真值皆為假 (Always False)。 純由其邏輯形式決定，在邏輯上不可能為真。 p ∧ ¬ p；標記為 ⊥
適真句 / 偶真句 (Contingent) 在某些賦值下為真，在其他賦值下為假。 無法單憑邏輯決定，必須依據經驗事實或現實世界狀態。 所有的原子語句（如 A、B）；A → B

2. 相互關係與對偶性

  • 恆真句的否定是矛盾句：若 ϕ 是恆真句，則 ¬ϕ 是矛盾句。
  • 矛盾句的否定是恆真句：若 ψ 是矛盾句，則 ¬ψ 是恆真句。
  • 兩者在邏輯上互為矛盾（Contradictory）。

3. 與「論證有效性」的深刻聯繫

恆真句與矛盾句並非僅是孤立的句式，它們與演繹論證的有效性直接等價：

對於任何論證：A1, A2, …, An ⊢ C

  1. 肯定表述（恆真句）：
論證有效 ⟺ (A1 ∧ A2 ∧ … ∧ An) → C 是恆真句 (Tautology)
  1. 否定表述（矛盾句）：
論證有效 ⟺ A1 ∧ A2 ∧ … ∧ An ∧ ¬ C 是矛盾句 (Contradiction)

（即反例集合是不一致的）。

4. 實質關係 vs. 邏輯關係

區分實質算子與邏輯算子至關重要：

  1. 實質條件句 (p → q) vs. 邏輯蘊涵 (Logical Implication)：
    • 實質條件句只是斷言「當前件真且後件假時為假，其餘為真」，它本身可能是適真句。
    • 只有當一個實質條件句是恆真句時，我們才稱前件邏輯蘊涵 (Logically implies) 後件。
  2. 實質等值句 (p ≡ q) vs. 邏輯等值 (Logical Equivalence)：
    • 實質等值句只斷言兩者真值相同。
    • 只有當一個實質等值句是恆真句時，兩者才是邏輯等值 (Logically equivalent)。

有效性與健全性

#演繹邏輯#核心概念#形式與真值
wiki/concepts/有效性與健全性.md

有效性 (Validity) 與 健全性 (Soundness)

在哲學與演繹邏輯中，有效性與健全性是評估一個演繹論證（Deductive Argument）是否成功的兩大基石。

1. 核心定義與本質

1.1 有效性 (Validity)

一個論證是形式有效 (Valid) 的，若且唯若：

  • 肯定表述：若所有前提皆為真，則其結論必然為真。
  • 否定表述：在邏輯上不可能 (Logically impossible) 出現所有前提皆真，但結論卻為假的情況。

關鍵原則：

  • 有效性純粹取決於論證的邏輯結構（形式 Form），而非個別語句的事實真假。
  • 有效論證是「保真（Truth-preserving）」的推論傳導器。
  • 「有效/無效」用於描述論證 (Arguments)；「真/假」用於描述語句/陳述 (Statements)。絕不可混淆！

1.2 健全性 (Soundness)

一個演繹論證是健全 (Sound) 的，若且唯若滿足兩大條件：

  1. 論證在形式上是有效 (Valid) 的。
  2. 該論證的所有前提在現實經驗中皆為真 (All premises are factually true)。
健全性 (Soundness) = 形式有效性 (Validity) + 前提事實真實 (True Premises)

推論：任何健全論證的結論必然為真。

2. 真值與有效性的所有組合矩陣 (Truth & Validity Matrix)

在邏輯學中，唯一絕對不可能出現的組合只有一種：「一個有效論證具備全真的前提，卻得出假的結論」。除此之外，任何真假組合皆可能存在！

2.1 有效論證 (Valid Arguments) 的真假組合

前提真值 結論真值 可能性 經典教材範例
前提皆真 結論真 可能 1. 阿里擊敗弗雷澤，則阿里是世界重量級拳王。(T)
2. 阿里擊敗了弗雷澤。(T)
\therefore 3. 阿里是世界重量級拳王。(T)
前提皆真 結論假 不可能 此組合絕不存在！若出現此情況，該論證必然是無效的。
前提有假 結論真 可能 1. 比爾·柯林頓是政治家，且他曾獲得奧運男子200公尺跨欄金牌。(F)
\therefore 2. 比爾·柯林頓是政治家。(T)
前提有假 結論假 可能 1. 月亮是由綠乳酪製成，且火星是由牛奶巧克力製成。(F)
\therefore 2. 月亮是由綠乳酪製成。(F)

2.2 無效論證 (Invalid Arguments) 的真假組合

無效論證的形式缺陷導致前提與結論缺乏邏輯保真傳導，因此所有真假組合皆可能出現：

前提真值 結論真值 經典教材範例 說明
前提皆真 結論真 1. 非洲是一個洲。(T)
2. 喬治·華盛頓橫渡德拉瓦河。(T)
\therefore 3. 綠花椰菜是一種蔬菜。(T)		 前提與結論皆真，但兩者毫無邏輯關聯 (p, q ⊢ r)，論證形式完全無效。
前提皆真 結論假 1. 若羅德島是南太平洋小島，則它比德州小。(T)
2. 羅德島比德州小。(T)
\therefore 3. 羅德島是南太平洋小島。(F)		 犯了肯定後項的謬誤。前提皆真卻得出假結論，反例證明形式必無效。
前提有假 結論真 1. 若鴨嘴獸是哺乳動物，則鴨嘴獸不下蛋。(F)
2. 鴨嘴獸不下蛋。(F)
\therefore 3. 鴨嘴獸是哺乳動物。(T)		 犯了肯定後項謬誤。前提皆假，但結論恰好為真。
前提有假 結論假 1. 黛安·范士丹代表紐約州參議員，或希拉蕊·柯林頓是俄亥俄州州長。(F)
2. 希拉蕊是俄亥俄州長。(F)
\therefore 3. 范士丹是紐約州參議員。(F)		 結構無效且前提與結論皆為假。

認識論重要推論：

  1. 單單得知一個論證是「有效的」，無法據此得知其前提或結論到底是真是假。
  2. 單單得知一個論證是「無效的」，我們也無法得出任何關於前提或結論真假的結論。

3. 健全論證的範例與哲學邊界

3.1 健全論證範例 (Sound)

  1. 十八尖山在新竹或者陽明山在高雄。(T)
  2. 並非「陽明山在高雄」。(T)
    \therefore 3. 十八尖山在新竹。(T)
    分析：形式為合法的選言三段論_Disjunctive_Syllogism（有效），且兩前提在地理事實上皆真，故為健全論證。

3.2 有效但不健全範例 (Valid but Unsound)

  1. 如果天下雨，則地面是濕的。(T)
  2. 天正在下雨。(假，現實晴天 F)
    \therefore 3. 地面是濕的。
    分析：形式為合法的假言推理_Modus_Ponens（有效），但前提 2 事實為假，故不健全，無法保證結論必然為真。

3.3 健全性的判定邊界

邏輯學專注於形式的有效性。至於前提是否符合現實客觀世界（Truth），屬於經驗科學、歷史學或形上學的領域：

  1. 存在一個無因的始源實體，或者存在一個無始無終的事物鏈條。(?)
  2. 並非「存在一個無始無終的事物鏈條」。(?)
    \therefore 3. 存在一個無因的始源實體。
    分析：形式完全有效（選言三段論），但人類理性與經驗無法確鑿證實前提真假，因而其 Soundness 超出純邏輯能裁決的範圍。

4. 相關鏈結

  • 語句與推論基礎：論證與陳述句、演繹與歸納

演繹與歸納

#核心概念#推論類型#演繹邏輯#歸納邏輯
wiki/concepts/演繹與歸納.md

演繹推論 (Deduction) 與 歸納推論 (Induction)

理性思維中有兩種主要的推論方式（Good Reasoning）：演繹 (Deduction) 與 歸納 (Induction)。兩者在結論與前提的關係、確定性以及知識擴展上具有根本區別。

1. 概念對比總覽

比較維度 演繹論證 (Deductive Argument) 歸納論證 (Inductive Argument)
定義特徵 前提的真必然且充分地確保結論的真 結論的內容超越 (go beyond) 前提所包含的訊息
評估標準 有效性 (Validity) 與 健全性 (Soundness) 歸納強度 (Inductive Strength) 與 說服力 (Cogency)
推論必然性 嚴格保真 (Truth-preserving)：邏輯上不可能前提真而結論假 蓋然性 (Probabilistic)：即使前提全真，結論仍有可能為假
認識論價值 揭示前提中已隱含的信息（不增加新事實訊息，但保證邏輯確定性） 向經驗學習，從有限觀察歸納通則，獲取真正嶄新的信念

2. 演繹論證 (Deduction)

2.1 演繹有效性 (Deductive Validity)

  • 肯定表述：若所有前提皆為真，則其結論必然 (must) 為真。
  • 否定表述：不可能所有前提為真，而結論卻為假。
  • 邏輯保真：前提的真實性在邏輯上完全確保（guarantee）了結論的真實性。
  • 形式決定：演繹是否有效完全由論證的形式結構決定，與個別事實內容無關。

2.2 範例

  1. 所有戰爭皆起於誤判。（前提）
  2. 伊拉克衝突是一場戰爭。（前提）
    \therefore 3. 伊拉克衝突起於誤判。（結論）
    （結構嚴密：只要前提為真，結論無法為假）

3. 歸納論證 (Induction)

3.1 歸納強度與蓋然性 (Inductive Strength & Probability)

  • 歸納論證不是演繹有效的，但好的歸納論證具備高度說服力 (Inductively Strong)：
    • 若其前提為真，在沒有其他相干資訊的情況下，期待結論為真比期待結論為假更為合理。
    • 其理由支持度是以機率 (Probability) 來衡量的。

3.2 經典範例

  1. 到目前為止，太陽每天早晨都升起。（前提）
    \therefore 2. 太陽明天早晨（很可能）依然會升起。（結論）
    （即使前提 100% 為真，邏輯上依然不能保證明天太陽絕不會發生意外不升起；但前提提供了相信結論的極佳理由）

3.3 經驗科學與歸納法

歸納推論是實證科學（如物理學、生物學）與人類日常生活累積新知識的基石：

向經驗學習 \longrightarrow 觀察規律性與相似模式 \longrightarrow 提出歸納假說 \longrightarrow 實驗求證與建立定律

發現的脈絡 (Discovery) 與 證成的脈絡 (Justification)

在哲學、認識論與科學哲學（由賴欣巴哈 Hans Reichenbach 明確區分）中，區分「發現的脈絡」與「證成的脈絡」是釐清思維合理性的重要工具。

1. 兩大脈絡的本質區別

比較維度 發現的脈絡 (Context of Discovery) 證成的脈絡 (Context of Justification)
關注重心 一個想法、假說或信念是如何被產生/想到的？ 這個信念或主張憑什麼被證實/證明為真？
研究領域 心理學、認知科學、社會學、傳記歷史 純粹邏輯學 (Pure Logic)、認識論、形式方法
解釋類型 因果說明 (Causal/Genetic Explanation) 理由證成 (Rational Justification)
評估指標 發生機制、歷史因緣、靈感來源 邏輯有效性、健全性、證據充分性

2. 經典案例剖析

2.1 牛頓與萬有引力

  • 發現的脈絡：相傳一顆掉落的蘋果砸到了牛頓的頭，促使他靈光一閃，聯想到天體引力。
    • 這是「心理學與生理上的促成原因」。
  • 證成的脈絡：蘋果打到頭不能用來證明萬有引力定律為真。要證成該理論，必須依賴數學推導、微積分運算以及開普勒行星運動數據的實證檢驗。

2.2 宗教與道德信念

「我相信上帝存在，因為我父母從小就是這樣教導我的。」

  • 此語句完全停留在發現的脈絡（解釋信念產生的歷史背景與社會化因果）。
  • 在證成的脈絡下，該信念是否合乎理性，必須檢驗其背後是否存在充足的論證支持（如宇宙論論證、目的論論證等）。

3. 邏輯學的學術使命

邏輯學嚴格專注於「證成的脈絡」：

  • 邏輯學不在乎某個論證是由誰提出、在什麼情緒下提出、或因為吃了什麼藥物產生的靈感。
  • 邏輯學唯一關心的是：前提是否在形式上保證了結論的真？論證是否有效？理由是否充分？
  • 混淆這兩個脈絡，常會落入「起源謬誤 (Genetic Fallacy)」或「訴諸人身 (Ad Hominem)」。

#語句邏輯#語意學#核心概念

真值函應 (Truth-Functionality) 與 邏輯連接詞

在語句邏輯（Sentential Logic, SL）中，整套系統的語意學奠基於真值函應原則。

1. 核心定義

1.1 真值與二值原則 (Bivalence)

在經典語句邏輯中，每個原子語句均被賦予且僅被賦予一個真值（Truth-value）：真 (True, T) 或 假 (False, F)。

1.2 真值函應 (Truth-Function)

真值函應是一個數學映射：

f: {T, F}n → {T, F}

它以一個或多個語句的真值作為輸入（Input），並產出唯一的真值作為輸出（Output）。

1.3 真值函應原則 (Principle of Truth-Functionality)

定義：在語句邏輯中，任何複合語句（Compound sentence）的真假值，完全且唯一地由其組成原子語句的真假值，以及連接詞所定義的真值函應所決定。

2. 五大基本真值函應連接詞

連接詞名稱 標準符號 替代符號 日常語言對應 真值特徵
否定 (Negation) ¬ p ∼ p 非、並非、不是 顛倒真值（T → F, F → T）
連言 (Conjunction) p ∧ q p · q 和、而且、並且、但 同真才真，其餘皆假
選言 (Disjunction) p ∨ q p ∨ q 或者（相容 or） 同假才假，其餘皆真
條件句 (Conditional) p → q p ⊃ q 若…則…、只要…就… 前真後假才為假，其餘皆為真
雙條件句 (Biconditional) p ↔ q p ≡ q 當且僅當、若且唯若 同值為真（同真或同假），異值為假

3. 非真值函應連接詞 (Non–Truth-Functional Connectives)

在日常自然語言中，許多連接詞不是真值函應的。它們除了成分句的真假外，還強烈依賴因果、時間、信念或認知狀態。

3.1 典型反例

  1. 認知運算子：「我知道 p (I know that p)」
    • 即使 p 是真的，我可能知道 p（為真），也可能不知道 p（為假）。單憑 p 的真值無法決定「我知道 p」的真值。
  2. 因果連接詞：「因為 (Because)」
    • 「阿圖的電腦當機，因為他的硬碟損壞了。」（若硬碟損壞確實是原因，句為真）
    • 「阿圖的電腦當機，因為海王星是一顆行星。」（前後兩句事實上皆為真，但此因果複句為假）
    • 因此「因為」無法僅靠前後兩句的真值來決定全句真假。
  3. 時間順序：「在…之前 (Before)」、「在…之後 (After)」
    • 柯林頓在小布希之前當總統 (T)；柯林頓在林肯之前當總統 (F)。兩者成分句皆真，但複句真值不同。

3.2 檢驗一個連接詞是否為真值函應的判準方法

檢驗法：若你能找到某種情況，其中成分語句的真值完全固定，但在某種背景下複句為真，在另一種背景下複句卻為假，則該連接詞絕非真值函應連接詞。

等同 (Identity) 與 確定描述詞 (Definite Descriptions)

在哲學與語言邏輯中，區分「是（is）」的文法多義性，並解決「指稱不存在事物的語句真假值」，催生了伯特蘭·羅素（Bertrand Russell）里程碑式的確定描述詞理論 (Theory of Definite Descriptions)。

1. 區分日常 "is" 的兩大哲學功能

日常自然語言中的 "is" 具有兩種根本相異的邏輯結構：

  1. 斷定屬性功能 (Predication / "is" of predication)：
    • 例：「約翰是高的（John is tall）」→ Tj。
    • 語意：將性質 T 賦予實體 j。
  2. 等同同一功能 (Identity / "is" of identity)：
    • 例：「馬克·吐溫是山繆·克萊門斯（Mark Twain is Samuel Clemens）」→ t = c。
    • 語意：兩個不同的專有名稱指涉客觀世界中的同一個個體。
    • 禁忌：不可將其翻譯為述詞 Ct（這會遮蔽等同的邏輯結構，使得相關論證無法被證明）。

2. 羅素的確定描述詞理論 (Theory of Definite Descriptions)

日常中我們常使用「那唯一的…（The so-and-so）」來指稱個體（如「現在的法國國王」、「天龍八部的作者」）。

羅素指出，一個形如「那個唯一的 P 具有性質 R」的語句，並非單純的單稱語句，而是包含了三項獨立斷言的複合存在量化命題：

  1. 存在性 (Existence)：至少存在一個 x 具有性質 P。
  2. 唯一性 (Uniqueness)：至多只有一個個體具有性質 P。
  3. 屬性歸屬 (Predication)：該個體具有性質 R。

符號化公式：

(∃ x)[Px ∧ (y)(Py → x = y) ∧ Rx]

3. 否定範圍歧義 (Scope of Negation)

確定描述詞最著名的哲學難題，在於當它與否定詞混用時產生的作用域歧義 (Scope Ambiguity)：

經典難題：「現在的法國國王不是禿頭。」（事實上法國目前為共和體制，無國王存在）

  1. 窄否定作用域（描述詞具主要範圍，Primary Scope）：
(∃ x)[Kx ∧ (y)(Ky → x = y) ∧ ¬ Bx]
  • 意義：世上存在唯一的現任法國國王，且他不禿頭。
  • 真值：假 (False)（因為法國根本沒有國王）。
  1. 廣否定作用域（否定詞具主要範圍，Secondary Scope）：
¬(∃ x)[Kx ∧ (y)(Ky → x = y) ∧ Bx]
  • 意義：並非「存在唯一的現任法國國王且是禿頭的」。
  • 真值：真 (True)（有效消解了排中律悖論）。

#語言哲學#符號化#否定語義#翻譯指南

自然語言否定深層語意：部分否定、全部否定與雙重否定

在日常語言（特別是英語與漢語）中，「否定」並非單純地在語句前加上負號（¬）。語法表面結構與底層邏輯結構之間常存在巨大落差。

一、 部分否定 (Partial Negation) vs. 全部否定 (Total Negation)

1. 兩者的對比與符號化

  • 部分否定：否定對象整體中的「一部分」（並非全都是）。
    • I do not know both of them. ⟹「他們兩位我並不是都認識。」
    • 符號化：¬(Ka ∧ Kb) ≡ ¬ Ka ∨ ¬ Kb。
  • 全部否定：否定對象整體中的「全部」（全都不）。
    • I know neither of them. ⟹「他們兩位我都不認識。」
    • 符號化：¬ Ka ∧ ¬ Kb ≡ ¬(Ka ∨ Kb)。

2. 三者以上（全稱範疇）的對比

  • 部分否定：
    • 句型：Not all... 或 All... not...
    • Not all birds can fly. / All birds cannot fly. ⟹「並非所有的鳥都能飛。」
    • 述詞邏輯公式：¬(x)(Bx → Fx) ⟺ (∃ x)(Bx ∧ ¬ Fx)。
  • 全部否定：
    • 句型：None...、No one...、Nobody...
    • No birds are mammals. ⟹「沒有鳥類是哺乳類。」
    • 述詞邏輯公式：(x)(Bx → ¬ Mx) ⟺ ¬(∃ x)(Bx ∧ Mx)。

3. 副詞的否定範疇

否定類型 常用副詞 邏輯意涵 自然語言例句
部分否定 not always, not completely, not wholly, not necessarily ¬(x)… Crows are not always black.（烏鴉未必總是黑色的。）
全部否定 never, nowhere, not at all, not in the least (x)¬… Crows are never black.（烏鴉絕不是黑色的。）

二、 雙重否定 (Double Negation) 句型與肯定等值轉換

雙重否定在修辭上加強語氣或表委婉，在邏輯語意上可等值轉化為肯定句：

1. 否定代詞 ＋ 否定前綴

  • Nothing is impossible. ⟹ 萬事皆有可能（一切皆可能）。
  • Nothing is changeless. ⟹ 萬物皆在變易。

2. 否定詞 ＋ without

  • The cleverest housewife cannot cook a meal without rice. ⟹ 巧婦難為無米之炊（烹飪必賴稻米）。
  • 符號化：(x)[(Hx ∧ Mx) → Rx]。

3. 否定詞 ＋ but（but 做關係代詞 that not / who not）

  • There is no man but has his faults. ⟹ 人皆有過（所有人都有缺點）。
  • 符號化：(x)(Px → Fx)。
  • It never rains but it pours. ⟹ 不雨則已，一雨傾盆（逢雨必驟）。

4. 否定詞 ＋ 半否定詞 (no little / no small)

  • He showed no little interest in the book. ⟹ 他對該書表現出極大興趣。

自然語言翻譯與充要條件 (Translation & Conditionals)

將日常自然語言符號化為語句邏輯形式時，最核心的挑戰在於精確掌握「充分條件」、「必要條件」以及常見的複合句型。

1. 條件句的語法與充要條件

在條件句 P → Q（或 P ⊃ Q）中：

  • P 稱為前件 (Antecedent)，是 Q 的充分條件 (Sufficient condition)：只要 P 發生，Q 必然發生（P 充分保證了 Q）。
  • Q 稱為後件 (Consequent)，是 P 的必要條件 (Necessary condition)：若沒有 Q，P 絕不可能成立（¬ Q → ¬ P）。

1.1 「如果 (If)」 vs. 「僅當 (Only if)」的根本差別

日常表述 邏輯符號化 前件 / 充分條件 後件 / 必要條件
If A, then B（若 A 則 B） A → B A B
B if A（B，如果 A） A → B A B
A only if B（A，僅當 B） A → B A B
Only if B, A（唯有 B，A 才會發生） A → B A B
A if and only if B（A 若且唯若 B） A ↔ B 互為充要條件 互為充要條件

記憶口訣：

  • 跟在 If 後面的是「前件（充分條件）」。
  • 跟在 Only if 後面的是「後件（必要條件）」。
  • 「A 僅當 B」（A → B）絕不等於「若 B 則 A」！例如：「你只有上課專心 (B) 才能及格 (A)」（A → B），表示不專心必不及格（¬ B → ¬ A），但光是專心還不保證一定及格。

2. 「除非 (Unless)」的標準與非標準翻譯

2.1 標準翻譯

「除非 A，否則 B (Unless A, B)」的意思是：如果不 A，那麼就會 B。

Unless A, B ⟺ ¬ A → B ⟺ A ∨ B
  • 例：「除非你用功 (A)，否則會被當掉 (B)」：
    • 符號化：¬ A → B（若不用功，則會被當）或 A ∨ B（你要麼用功，要麼被當）。

2.2 強調充要條件（排斥意義）的非標準情境

若語境強烈暗示「兩者互為充要條件」（例如「我明天陪你打球，除非明天下雨」且預設不下雨必定去打球）：

G ↔ ¬ R ⟺ (G → ¬ R) ∧ (¬ R → G)

3. 複合否定句型對照表

日常語句句型 英文對照 邏輯符號化（標準式） 邏輯等值式 (De Morgan)
不會既 A 又 B（並非兩者兼具） Not both A and B ¬(A ∧ B) ¬ A ∨ ¬ B
既不是 A 也不是 B（兩者皆非） Neither A nor B ¬ A ∧ ¬ B ¬(A ∨ B)

4. 翻譯分析標準步驟

  1. 辨識主連接詞 (Main Connective)：由外向內觀察語句結構與標點停頓。
  2. 劃定括弧與作用域 (Scope)：特別留意否定詞「並非 (It is not the case that)」的控制範圍。
  3. 逐層拆解成分句：直至每個組件皆為原子語句。
  4. 雙向真值檢驗：檢查在所有情況下，自然語言語句的真假條件是否與邏輯式的真值表完全吻合。

語句形式 (Logical Form) 與 取代實例 (Substitution Instance)

理解「語句常元」與「語句變元」、「語句」與「語句形式」的差別，是掌握形式邏輯推論規則與語法學的基石。

1. 變元 (Variables) vs. 常元 (Constants)

  • 句常元 (Sentence Constants: A, B, C …)：代表特定的、明確的陳述句（Definite statements），具有具體的客觀真假值（例如 A:「清華大學在新竹」）。
  • 句變元 (Sentence Variables: p, q, r …)：佔位符號，代表任意的陳述句（Indefinite statements）。變元本身沒有真值。

2. 語句 (Sentence) vs. 語句形式 (Sentence Form)

  • 語句形式 (Sentence Form)：僅由語句變元與邏輯連接詞所構成的公式（如 p ∧ q、p → (q → p)）。它沒有真值，但具有真值條件 (Truth conditions)，可畫出真值表。
  • 具體語句 (Sentence)：由句常元構成（如 A ∧ B），代表真值表中的某一種具體真值賦值狀態。

3. 取代實例 (Substitution Instance)

將一個語句形式中的所有語句變元，替換為合式語句（wff），所得出的具體語句稱為該形式的取代實例。

3.1 取代兩大鐵律

  1. 只能對變元取代：不能對常元或邏輯連接詞進行取代。
  2. 同名變元同時代換：語句形式中所有出現的相同變元，必須同時替換為同一個語句。
    • （但不同的變元允許代換為相同的語句，因為變元代表任意語句）。

[!CAUTION] 嚴格限制：取代實例的邏輯結構絕不能比原語句形式更簡單！

  • 例：A ∨ B 可以是變元 p 的取代實例，也可以是 p ∨ q 的取代實例。
  • 但 A 絕不能是 p ∨ q 的取代實例！

4. 一對一邏輯形式 (One-One Logical Form) 與 形式判定定理

任何一個複合語句可對應到多個形式層次。其中最精確、最重要的概念是一對一邏輯形式 (One-One Logical Form / Expanded Form)：

  • 定義：將語句中出現的每一個相異原子字母替換為一個相異變元，且所有相同的字母一律替換為相同的變元（例如 (A ∨ B) → (C ∧ A) 的一對一形式為 (p ∨ q) → (r ∧ p)）。

4.1 避免誤判適真句 (Contingency)

  • 考慮排中律語句：A ∨ ¬ A。
    • A ∨ ¬ A 是變元 p 的一個取代實例。
    • 變元 p 的真值表含有一 T 一 F。
    • 重要警示：我們絕不能因此稱 A ∨ ¬ A 為適真句！因為 p 並不是它的一對一形式，p ∨ ¬ p 才是。在 p ∨ ¬ p 下，真值全為 T（恆真句）。

4.2 形式判定三項根本定理

  1. 定理一：若一個語句具有某個「非一對一」的恆真形式，則在其「一對一形式」下必然也是恆真句。
    • 例：{[(A ∧ B) → (C ∨ D)] ∧ (A ∧ B)} → (C ∨ D) 是 [(p → q) ∧ p] → q 的實例（非一對一，但恆真），則它的一對一形式必然也是恆真句。
  2. 定理二：若一個語句的一對一形式是恆真句，它未必有其他恆真形式。
  3. 定理三（黃金裁決準則）：若一個語句的一對一形式是適真句 (Contingency)，則它在任何其他形式下絕不可能成為恆真句或矛盾句！

論證 (Argument) 與 陳述句 (Statement)

在哲學與邏輯學中，「論證」是探討理性思考與辯護的核心單位。

1. 論證的要素 (The Elements of an Argument)

1.1 論證的定義

論證 (Argument) 是一組具有特定邏輯結構的陳述句系列（Sequence of statements）：

  • 前提 (Premises)：提供理由與證據，用以支持或使人接受結論的語句。
  • 結論 (Conclusion)：論證所要辯護、確立或證成的主張。
  • 推論關係 (∴)：使用「所以（Therefore，符號 \therefore）」等語詞標示前提對結論的理由支持關係。

1.2 日常語言中的指示詞 (Indicators)

在自然語言中，可透過指示詞快速辨識論證的前提與結論：

  • 前提指示詞 (Premise Indicators)：表示其後跟隨的是前提。
    • 例：「因為」、「既然」、「由於」、「鑑於」、「基於…理由」。
  • 結論指示詞 (Conclusion Indicators)：表示其後跟隨的是結論。
    • 例：「所以」、「因此」、「因而」、「結果是」、「由此可推知」。

2. 陳述句 (Statements) 的本質

並非所有語句序列都是論證：

  1. 陳述句（或命題）：具有真假值 (Truth Value) 的語句，即不是為真（True）就是為假（False）。只有陳述句才能充當論證的前提與結論。
  2. 非陳述性語句：日常語言中的命令、疑問、驚嘆、祈使、請求句，通常不直接描述客觀事態，嚴格來說無真假可言：
    • 命令句：「開門！」
    • 疑問句：「有外星人嗎？」
    • 表達感受：「好加在！」
    • 請求句：「麻煩幫我開門！」
  3. 語境與脈絡 (Context)：
    • 不能僅憑文法結構判定是否為陳述句。
    • 例：主管向上屬問「誰是這裡的老大？」，文法上為問句，但實際言談脈絡中所表達的事態是：「我是這裡的老大」（陳述句）。

3. 重要哲學區分：因果說明 (Explanation) vs. 理由證成 (Justification)

即便一個語句系列全部由陳述句組成，它仍不一定是論證。關鍵在於語句之間是否存在「提供理由以證成結論」的關係。

比較維度 因果說明 / 解釋 (Explanation) 理由證成 / 論證 (Argument / Justification)
核心問題 「這件事為什麼會發生？」 「我憑什麼相信這是真的？」
提供內容 物理原因 (Cause)、起源 (Genetic origin)、條件 理由 (Reason or Ground)、證據 (Evidence)
目標目的 解釋已發生的客觀事實之成因 說服 (Convince) 他人或自己接受結論為真
起點假設 雙方已預設結果為真 結果尚未被確立，需要被辯護

3.1 經典範例對照

  • 因果說明（非論證）：

    「小珍很氣他，因為他撞壞了她的車。」
    （雙方已知「小珍生氣」是既成事實，語句僅在說明小珍生氣的原因）。

    「我相信上帝，因為我從小被這樣教育長大。」
    （僅說明產生信念的心理或家庭發生起源，並非上帝存在的證成理由）。

  • 理由證成（論證）：

    「小珍應該很氣他，因為他撞壞了她的車。」
    （說話者不確定小珍是否生氣，提出撞壞車作為支持「小珍應該會生氣」的合理理由）。

    「生命是有意義的；如果沒有上帝，生命將毫無意義；所以，我相信上帝存在。」
    （提供邏輯理由來辯護上帝存在的結論）。

3.2 判別心法

觀察發話者或作者的意圖與脈絡：

  • 若作者假設結果已為真，僅探討其促成因素 → 因果說明。
  • 若作者試圖確立、證明或說服該結果成立 → 論證。

述詞邏輯語意學與無效性證明

在語句邏輯中，我們能透過有限真值表機械性地判定任何論證。但在述詞邏輯中，不存在有限的通盤決定程序（邱奇定理 Church's Undecidability Theorem）。

1. 述詞邏輯中的「解釋 (Interpretation)」

一個完整的述詞邏輯解釋（模型 M）必須包含五大要素：

  1. 論域 (Domain D)：一個非空的實體對象集合。
  2. 常元指派：為每個個體常元指派 D 中的一個特定成員。
  3. 述詞外延指派：為每個性質/關係述詞指定外延集合（哪些個體具有該性質）。
  4. 語句真值指派：若含有獨立命題變元，指定其真假值。
  5. 量詞語義賦值：依據 D 中的成員全面評估全稱與存在量詞。

2. 為什麼推論規則不能證明無效性？

  • 自然演繹推論規則全部是保真的 (Truth-preserving)。
  • 演繹證明只能從真前提導出真結論，絕對無法構造出反例。
  • 因此，要證明論證無效，唯一 sanctioned 的科學途徑就是「構造反例解釋 (Counterexample Interpretation)」：提供一個特定的模型，使得該論證所有前提皆為真，但結論卻為假。

3. 構造反例的三大方法

3.1 方式一：日常經驗事實反例

  • 構造自然語言實例，使前提符合已知事實（真），而結論違背事實（假）。
  • 例：
    1. 所有人都會死。(T)
    2. 所有狗都會死。(T) \therefore 3. 所有人都是狗。(F！) ⟹ 證明形式無效。
  • 缺點：經驗事實有時具有模糊性或時代變異性。

3.2 方式二：數學模型反例（極為嚴謹）

  • 利用整數、奇偶數、大小關係建立絕對無爭議的反例：
    • Domain = {正整數}
    • Fx: x 是 4 的倍數；Gx: x > 1；Hx: x > 2。
    • 前提全真但結論為假，確鑿判定無效。

3.3 方式三：有限論域展開式法 (Finite Domain Expansion Method)

  • 標準機械化反例工具：
    1. 設定微型論域 Domain = {a, b}（通常 2 個個體即可證偽大多數無效論證）。
    2. 將全稱語句展開為連言 (∧)，存在語句展開為選言 (∨)。
    3. 轉化為語句邏輯形式後，使用短真值表法強制設定結論為假、前提為真，反向求解賦值 V。

本篇為課堂常見的典型演繹論證推導題目，示範本 Wiki 的解題與歸檔標準。

題目描述

給定以下三項前提，證明結論 ¬ A：

  1. A → B
  2. B → C
  3. ¬ C 目標結論：¬ A

符號化與解題分析

  • 涉及概念：假言推理_Modus_Ponens、否定後項_Modus_Tollens、自然演繹法_Natural_Deduction。
  • 解題策略：
    • 方法一（直接推導）：可先由前提 2 與前提 3 利用 MT 導出 ¬ B，再由前提 1 與 ¬ B 利用 MT 導出 ¬ A。
    • 方法二（假言三段論 HS）：先由前提 1 與前提 2 串接出 A → C，再與前提 3 利用 MT 得出 ¬ A。

逐步證明 (Step-by-step Proof)

採用標準自然演繹格式（方法一）：

前提：
1. A -> B                      (前提)
2. B -> C                      (前提)
3. ~C                          (前提)

證明步驟：
4. ~B                          (2, 3 否定後項 MT)
5. ~A                          (1, 4 否定後項 MT)
Q.E.D.

易錯思維與哲學洞察 (Pitfalls & Insights)

  1. 不可前推後否：初學者容易企圖從前提 1 與前提 3 直接得到結論，但 A → B 與 ¬ C 之間必須透過仲介命題 B 來搭橋。
  2. 保真性驗證：因為每一步均使用保真的推論規則（MT），整個推導保證具備形式有效性 (Validity)。

範例習題 002：述詞邏輯演繹推導與量詞規則限制

本篇示範如何在綜合包含全稱條件句、條件證明法 (CP) 以及全稱一般化 (UG) 的進階述詞邏輯題目中，嚴謹完成推導並成功避開規則限制陷阱。

題目描述

給定以下三項前提，證明結論 (x)[Ax → (Cx ∧ Dx)]：

  1. (x)(Ax → Bx)
  2. (x)[Bx → (Ax → Fx)]
  3. (x)[(Cx ∧ Dx) → ¬ Fx] 目標結論：(x)[Ax → ¬(Cx ∧ Dx)]

題意分析與戰略構思

  1. 結論特徵：結論是一個全稱條件句 (x)[Ax → …]。
  2. 核心戰略：
    • 結論的主連接詞是全稱量詞 (x)，次連接詞是條件句 →。
    • 最佳策略：在全稱層次，先對各前提使用 UI 提取出任意準變元 x；
    • 隨後在命題層次，假設前件 Ax（開啟 CP），在子區間內推導出後件 ¬(Cx ∧ Dx)；
    • 藉由 CP 解除假設得到 Ax → ¬(Cx ∧ Dx)；
    • 最後檢驗 x 是否已解毒（AP 已消去），合法使用 UG 加上全稱量詞！

逐步證明 (Step-by-step Proof)

前提：
1. (x)(Ax -> Bx)                              (前提)
2. (x)[Bx -> (Ax -> Fx)]                      (前提)
3. (x)[(Cx · Dx) -> ~Fx]                      (前提)  /∴ (x)[Ax -> ~(Cx · Dx)]

證明步驟：
4.  | Ax                                      (AP，假設前件，求證 ~(Cx · Dx))
5.  | Ax -> Bx                                (1 UI，使用變元 x)
6.  | Bx -> (Ax -> Fx)                        (2 UI，使用變元 x)
7.  | (Cx · Dx) -> ~Fx                        (3 UI，使用變元 x)
8.  | Bx                                      (4, 5 MP)
9.  | Ax -> Fx                                (6, 8 MP)
10. | Fx                                      (4, 9 MP)
11. | ~~Fx                                    (10 DN)
12. | ~(Cx · Dx)                              (7, 11 MT)
13. Ax -> ~(Cx · Dx)                          (4-12 CP，消去假設 AP，變元 x 獲得自由)
14. (x)[Ax -> ~(Cx · Dx)]                     (13 UG，變元 x 具完全任意性，合法添加全稱量詞)
Q.E.D.

易錯思維與規則檢核 (Pitfalls & Verification)

  1. 第 14 步 UG 的合法性核查：
    • 檢查變元 x 是否為常元？ → 否，是準變元。
    • 檢查變元 x 是否來自先前 EI 列？ → 否，本題全無 EI。
    • 檢查變元 x 是否自由出現在尚未消去的 AP 中？ → 否！步驟 4 的 AP 已經在步驟 13 透過 CP 完全消去 (Discharged)，此時 x 已徹底解毒，重獲代表「論域中任意個體」的資格，故步驟 14 的 UG 完美合法！

習題解析 Ch. 1：有效性、健全性與一致性觀念辨析

本篇收錄第一章經典哲學概念辨析問答（Exercise 1-3），釐清初學者最容易混淆的邏輯核心概念。

核心問題深入剖析

Q1: 前提全真且結論為真的論證，是否必然是演繹有效的？

答案：否！

  • 深入分析：論證的有效性取決於邏輯形式而非個別語句的事實真假。
  • 經典反例：
    1. 1 + 1 = 2 (真)
    2. 清華大學旁有座十八尖山 (真)
      \therefore 3. 貢丸與米粉是新竹名產 (真)
    • 形式為 p, q ⊢ r。在同樣的形式下，我們可以構造出假結論（例如把結論換成「台灣是南太平洋的小島」）。前提與結論缺乏邏輯保真傳導關係，故形式無效。

Q2: 演繹有效論證是否可能具有假的前提？

答案：是！

  • 深入分析：有效論證唯一排除的情況只有一種：前提全真但結論為假。
  • 經典有效反例（含假前提）：
    1. 清華大學旁有座十八尖山，或者貢丸與米粉是新竹名產。(T)
    2. 貢丸與米粉不是新竹名產。(F)
      \therefore 3. 清華大學旁有座十八尖山。(T)
    • 形式為合法的DS（有效），但前提 2 在事實上為假。

Q3: 健全論證 (Sound Argument) 有沒有可能是無效的？

答案：絕對不可能！

  • 深入分析：根據定義：
健全論證 = 形式有效 (Valid) + 前提事實全真 (All True Premises)

健全論證必然是有效論證，且其結論在現實中必然為真。

Q4: 不一致的語句集合中，是否有成員可能為真？

答案：完全可能！

  • 深入分析：不一致性（Inconsistency）僅斷定所有成員不可能「同時」為真，但絕不代表集合內所有語句都是假的。
    • 例：{今天是晴天 (T),\ 今天不是晴天 (F)} 是不一致集合，但其中第一句話為真。

Q1: 為什麼不能用單一字母 P 來縮寫否定句「George 不是公眾人物」？

答案：因為 P 是原子語句常元。在語法學上，原子語句不含任何邏輯運算子。若用 P 代表否定句，會遮蔽該句子內在的否定邏輯結構，導致後續演繹時無法套用如 DN、MT、DS 等推論規則。應符號化為 ¬ P。

Q2: 為什麼算子「眾所周知 (It is well known that ...)」不是真值函應的？

答案：因為複句真值無法單由成分句的真假唯一決定！

  • 「2 + 2 = 4」為真 ⟹「眾所周知 2+2=4」為真 (T)。
  • 「小明暗戀小華」事實上為真 ⟹「眾所周知小明暗戀小華」事實上為假 (F)。
  • 兩者成分句皆真，但加上前綴後一真一假，違背了真值函應原則。

Q3: Lady Gaga 經典句子比較：原子句 vs. 複合句

  1. 「Lady Gaga 與 Stefani Joanne 都是著名公眾人物」：
    • ⟹ 複合句 (Compound)。因為 "and" 在此並無「共同行動」之意，可無損拆解為兩句獨立陳述的連言。
  2. 「Lady Gaga 與 Stefani Joanne 是終生摯友」：
    • ⟹ 原子句 (Atomic)。因為 "and" 表達的是兩人間的相互二元關係（是朋友）。若硬拆成「她是朋友且她是朋友」則失去原本語意。

一、 含未知變元的快速短路求值 (Ex 3-2)

當複合語句中含有未知真值的命題變元（如 Q, R = ?）時，善用實質條件句與排中律的代數特徵可極速解題：

  1. 題目：¬ C → (D → Q)，已知 V(C)=F, V(D)=F。
    • 解析：在後件 D → Q 中，前項 D 為假。根據實質條件句定義，假前項保證條件句必為真，故 D → Q = T（不論 Q 為何）。
    • 前件 ¬ C = T；T → T = T。
    • 答案：V = T。
  2. 題目：¬[R ∧ ¬ R]，已知 V(R) = ?。
    • 解析：R 與 ¬ R 必然互為矛盾，其連言 R ∧ ¬ R 恆等於假 (F)。否定假命題必然為真。
    • 答案：V = T。

二、 短真值表法判定有效性 (Ex 3-8, 3-10)

短真值表法藉由「強制假設反例存在（前提皆真且結論為假）」，以最小代價判定有效性：

示範 1：證明有效性（導出矛盾）

論證：(A ∧ B) → C,\ A ⊢ B → C

  1. 假設結論為假：V(B → C) = F ⟹ V(B) = T,\ V(C) = F。
  2. 假設前提皆為真：
    • 前提 2：V(A) = T。
    • 此時 A ∧ B = T ∧ T = T。
    • 帶入前提 1：前項為 T 但後項 C = F，導致 (A ∧ B) → C = F，與前提全真的假設產生致命矛盾！
  3. 結論：反例不可能存在，論證有效 (Valid)。

示範 2：證明無效性（成功構作反例賦值）

論證：P → Q,\ R → S,\ R ∨ Q ⊢ P ∨ S

  1. 假設結論為假：V(P ∨ S) = F ⟹ V(P) = F,\ V(S) = F。
  2. 嘗試為前提賦值使全為真：
    • 前提 1：P → Q，因 P = F，不論 Q 為何皆為真。取 V(Q) = T。
    • 前提 2：R → S，因 S = F，為使全句真，必取 V(R) = F。
    • 檢驗前提 3：R ∨ Q = F ∨ T = T（成立！）。
  3. 成功找到一組完整反例賦值：
V(P) = F,\ V(Q) = T,\ V(R) = F,\ V(S) = F
  1. 結論：前提全真而結論為假，論證無效 (Invalid)。

三、 集合一致性檢測 (Ex 3-11)

集合：{B → A,\ C → B,\ ¬ C ∧ A}

  • 目標：尋找是否存在一組賦值使全體成員同時為真。
  • 由 ¬ C ∧ A = T ⟹ V(C) = F,\ V(A) = T。
  • 帶入 C → B：因 C = F，條件句自動為真。
  • 帶入 B → A：因後項 A = T，條件句自動為真。
  • 結論：當 V(A)=T, V(C)=F, V(B)=任意 時，全體成員同時為真，故該集合為一致 (Consistent)。

3. A -> (B -> C)               (1 Exp，解包複合前件)

3. ~(A · B) v C                (1 Impl)
4. (~A v ~B) v C               (3 DeM)

1. (B · C) v D                 (前提)
2. ~C                          (前提)  /∴ D
3. D v (B · C)                 (1 Comm，將單項移至左側以利分配)
4. (D v B) · (D v C)           (3 Dist，展開為兩選言項之連言)
5. D v C                       (4 Simp，提取關鍵項，割離不要的 B)
6. D                           (2, 5 DS)
Q.E.D.

三、 後設邏輯精華：析取範式 (DNF) 與 表達完備性 (Ex 4-14)

1. 表達完備性定理 (Expressive Completeness)

算子集合 {¬, ∧, ∨} 甚至 {¬, ∨} 具有表達完備性：任何真值表所定義的真值函應，都可以僅使用這組算子寫出合式公式。

2. 析取範式 (Disjunctive Normal Form, DNF) 建構法

對於任何真值表：

  1. 鎖定所有輸出為真 (T) 的列。
  2. 對每一列，將輸入變元寫成連言項（若變元為 T 則寫原句，若為 F 則加否定號）。
  3. 將所有真值列的連言項以選言符號（∨）串接。
  • 範例：若真值表在第一列 (T, T) 與第三列 (F, T) 為真：
DNF Formula = (p ∧ q) ∨ (¬ p ∧ q)

這從數學上證明了一階語句邏輯語法的完整性與完備性。

≡ ¬(∃ x)(Dx ∧ Mx)

習題解析 Ch. 8：述詞邏輯語意學與反例模型構造

本篇精選第八章及期末小考關於構造數學模型反例、微型論域展開式證偽無效論證的核心技巧。

一、 構造數學模型反例 (Ex 8-2)

在述詞邏輯中，要證明論證無效，最嚴密的方法是建立一個數學模型解釋，使前提皆真而結論為假：

題目：(∃ x)(Ax ∧ Bx),\ (∃ x)(Bx ∧ Cx) ⊢ (∃ x)(Ax ∧ Cx)

  • 直覺誤區：很多初學者誤以為由「有些 A 是 B」且「有些 B 是 C」能推得「有些 A 是 C」。
  • 構造嚴格數學反例：
    • 設定 Domain = {自然數 1, 2, 3 …}
    • Ax: x 是偶數
    • Bx: x 能被 3 整除
    • Cx: x 是奇數
  • 檢驗模型：
    • 前提 1：存在自然數既是偶數又能被 3 整除（如 x = 6）⟹ 真 (True)。
    • 前提 2：存在自然數能被 3 整除且是奇數（如 x = 3）⟹ 真 (True)。
    • 結論：存在自然數既是偶數又是奇數 ⟹ 假 (False)！
  • 結論：成功在數學模型中確立反例，論證形式無效 (Invalid)。

二、 微型論域展開式短真值表證偽法 (Ex 8-3, 期末小考 6)

題目：(∃ x)(Ax → Bx),\ (x)[(Ax ∧ Bx) → Cx] ⊢ (x)Cx

  1. 設定微型論域：Domain = {a, b}。
  2. 寫出命題展開式：
    • 前提 1 展開：(Aa → Ba) ∨ (Ab → Bb)
    • 前提 2 展開：[(Aa ∧ Ba) → Ca] ∧ [(Ab ∧ Bb) → Cb]
    • 結論展開：Ca ∧ Cb
  3. 強制設定反例賦值：
    • 令結論為假：取 V(Ca) = F,\ V(Cb) = F。
    • 令前提 1 為真：取 V(Aa) = T,\ V(Ba) = T ⟹ Aa → Ba = T。
    • 帶入前提 2 檢驗：若 Aa ∧ Ba = T 且 Ca = F，則 (Aa ∧ Ba) → Ca = F（衝突！）。
    • 調整賦值：
      • 改取 V(Aa) = F ⟹ Aa → Ba = T（前提 1 真）；且 Aa ∧ Ba = F ⟹ (Aa ∧ Ba) → Ca = T。
      • 同理取 V(Ab) = F ⟹ (Ab ∧ Bb) → Cb = T。
  4. 成功構造反例賦值：
Domain={a, b},\ V(Aa)=F,\ V(Ab)=F,\ V(Ca)=F,\ V(Cb)=F

在此模型下，兩前提皆為真，但結論 Ca ∧ Cb 為假！ 5. 裁決結論：論證形式無效。

本篇精選第九章與期末小考中關於識別無效量詞步驟、先 EI 後 UI 策略、QN 破除否定量詞以及綜合 CP/UG 的實戰推導。

一、 抓出常見無效推論步驟 (Ex 9-2 經典辨析)

在演繹證明作業中，初學者最常違反量詞五大限制：

  1. 禁令：單向規則不可作用於局部子句：
    • 錯誤步驟：(x)[(Hx ∧ Kx) → Mx],\ (∃ x)(Hx ∧ Kx) ⊢ (∃ x)Mx（第 4 步直接用 MP 推出 Mx）。
    • 辨析：(Hx ∧ Kx) → Mx 是處在量詞控制下的子式，不是獨立語句，不能直接與第 2 步施行 MP！必須先將量詞消去。
  2. 禁令：EI 必須引進全新變元：
    • 錯誤步驟：第 3 步已由 UI 引進 y 導出 (Gy ∨ Hy) → My，第 4 步又對 (∃ x)(Fx ∧ ¬ Mx) 做 EI 引進 y 導出 Fy ∧ ¬ My。
    • 辨析：y 已經被使用過，EI 必須引進全新的準變元（如 z），否則會造成不同存在項強行重合的嚴重錯誤！
  3. 禁令：不可對 EI 引進的變元做全稱一般化 (UG)：
    • 錯誤步驟：由存在引例得 Px，再對 Px 做 UG 導出 (x)Px。
    • 辨析：以偏概全！EI 的變元代表未知的特定個體，失去了任意性，嚴禁使用 UG。

二、 結合 QN 與 MT 的經典證明 (期末小考 7)

題目：(∃ x)(Ax ∧ Bx) → (y)Cy,\ ¬ Ca ⊢ (x)(Ax → ¬ Bx)

前提：
1. (∃x)(Ax · Bx) -> (y)Cy      (前提)
2. ~Ca                         (前提)  /∴ (x)(Ax -> ~Bx)

證明步驟：
3. (∃y)~Cy                     (2 EG)
4. ~(y)Cy                      (3 QN，將存在否定化為否定全稱)
5. ~(∃x)(Ax · Bx)              (1, 4 MT，成功觸發前件否定)
6. (x)~(Ax · Bx)               (5 QN，打開括弧前面的否定號！)
7. ~(Ax · Bx)                  (6 UI，提取任意代表 x)
8. ~Ax v ~Bx                   (7 DeM)
9. Ax -> ~Bx                   (8 Impl)
10. (x)(Ax -> ~Bx)             (9 UG，變元 x 具完全任意性)
Q.E.D.

戰略點評：第 5 步到第 6 步是整個證明的命脈。¬(∃ x) 不能直接做 UI，必須先透過 QN 翻轉成 (x)¬，才能合法施展 UI！

一、 自然語言深層關係改寫 (Paraphrasing Ex 10-4)

日常哲理諺語通常包含隱含的「時間」與「空間」全稱概括：

  1. 「人的工作永遠做不完。」
    • 深層改寫：每個人在任何時間都有某些工作是做不完的。
    • 符號化：(x){Px → (y)[Ty → (∃ z)(Wzx ∧ ¬ Dzxy)]}

二、 多重量詞無效性數學反例 (Ex 10-8)

題目：(∃ x)(y)Fxy ⊢ (x)(y)Fyx

  • 反例模型（自然數乘法單位元素）：
    • Domain = {自然數 1, 2, 3 …}
    • Fxy: x · y = y
  • 檢驗：
    • 前提：存在自然數 x = 1，對所有自然數 y 滿足 1 · y = y（前提為真）。
    • 結論：對所有自然數 x, y 滿足 y · x = x（例如 2 · 3 ≠ 3，結論顯然為假！）。
  • 結論：多重量詞的先後順序交換是形式無效的！

2.  | | (∃x)Fx                         AP /∴ P

一、 十大是非題陷阱與反例剖析 (30%)

1. 反事實條件句 ≠ 實質條件句

  • 命題：「若太陽從西邊升起，我就請你吃飯。」可翻為實質條件句。
  • 答案：F
  • 辨析：該句語用語意為「絕不請吃飯」。若譯為實質條件句，假前項保證全句為真，造成語意嚴重扭曲。參閱實質條件句的哲學爭論與證成。

2. 語法結構 ≠ 語意等值

  • 命題：「小明不在家」的否定句是「小明在家」。
  • 答案：F
  • 辨析：「小明不在家」(¬ A) 的語法否定句是「並非小明不在家」(¬¬ A)。雖然 ¬¬ A ⟺ A，但 A 是肯定句，兩者語法結構不同。

3. 全假集合的一致性

  • 命題：若語句集中所有語句都同時為假，則此集合不一致。
  • 答案：F
  • 辨析：不一致是指「不可能同時為真」，但「可以同時為假」。例如 {清華在巴黎,\ 台大在柏林} 全假，但集合顯然是一致的。

4. 前提一致且結論為假 ≠ 論證無效

  • 命題：論證前提一致且結論為假，則論證必無效。
  • 答案：F
  • 辨析：有效論證完全可以具備假前提與假結論（例如 A → B, A ⊢ B，當 A 事實為假時，結論 B 亦可為假，但形式為 MP 完全有效）。

5. 無效形式的取代實例可以有效

  • 命題：無效論證形式的取代實例都是無效論證。
  • 答案：F
  • 辨析：無效形式 p, q ⊢ r 的取代實例可以是 A → B, A ⊢ B（有效論證）。有效性只需具備「至少一個」有效形式即可。

6. 有效論證添加前提的單調性 (Monotonicity)

  • 命題：在有效論證的前提中添加新前提，新論證仍有效。
  • 答案：T
  • 辨析：古典演繹邏輯具備單調性。添加新前提絕不會破壞既有的保真推導鏈；語意上，不一致的反例集加入新語句依然是不一致的。

本篇整合課堂 7 次「語句邏輯小考」的全部核心試題，涵蓋論證是非觀念、高階自然語言符號化、短真值表檢驗、18 條規則一題多解、CP/IP 定理推導與概念單選題。

第一單元：論證有效性與集合一致性是非觀念（小考 1）

  1. 前提與結論都真的論證不必然有效：
    • 清華在新竹 (T)，台大在台北 (T) ⊢ 清華在新竹 (有效)。
    • 清華在新竹 (T) ⊢ 台大在台北 (T)（無邏輯關聯，無效！）。
  2. 結論為假的有效論證，其前提「至少有一為假」，不必然全假。
  3. 一致的集合所有語句可以全部為假（只要邏輯上有可能同真即可，如 {清華在澎湖,\ 台大在金門}）。
  4. 前提集不一致的論證必然是有效的（平凡有效 Trivially Valid，因為在邏輯上絕不可能出現「前提全真而結論為假」）。
  5. 結論為假的有效論證，其前提集可以一致，也可以不一致。

第二單元：自然語言複雜符號化五大經典句型（小考 2）

  1. 貨幣供給與通貨膨脹（De Morgan 轉換）：
    • 「如果我們不控制貨幣供給或不打破石油輸出國家組織的力量，我們將無法控制通貨膨脹。」
    • ⟹ (¬ M ∨ ¬ O) → ¬ I ⟺ ¬(M ∧ O) → ¬ I ⟺ I → (M ∧ O)
  2. 小明畢業成績（嵌套條件句）：
    • 「如果小明有好的畢業成績，那麼他就會找到好工作且賺很多錢——假如他沒有追求其他目標的話。」
    • ⟹ G → (¬ O → (J ∧ L)) ⟺ (G ∧ ¬ O) → (J ∧ L)
  3. 除非（Unless）與政府赤字：
    • 「如果我們增加稅收並消除政府浪費支出，那麼，除非有自然的大災害，否則赤字將會降低。」
    • ⟹ (T ∧ S) → (N ∨ D) ⟺ (T ∧ S) → (¬ N → D)
  4. 兩者並非皆是（Not both ... but ...）：
    • 「並非小明與小華兩者都是笨蛋，但小芬卻是。」
    • ⟹ ¬(A ∧ B) ∧ C ⟺ (¬ A ∨ ¬ B) ∧ C

第三單元：短真值表檢驗有效性與集合一致性（小考 3）

  • 檢驗論證無效性核心心法：強制設定結論為假，嘗試為前提賦值使全為真。
    • 例：P → Q,\ (Q ∧ R) → P ⊢ ¬ Q
    • 取 V(Q)=T, V(P)=T, V(R)=T，所有前提均為真且結論 ¬ Q = F 成功，判定無效！
  • 檢驗集合一致性核心心法：尋找至少一組賦值使全體成員同時為真。
    • 集合 {B → A,\ C → B,\ ¬ C ∧ A} 在 V(A)=T, V(C)=F 時所有語句恆真，判定一致。

第四單元：18 條規則自然演繹一題多解精華（小考 4 & 5）

經典難題：(A ∧ B) ∨ (C ∧ D),\ ¬ C ⊢ A

  • 解法一（利用 DeM 與 Add）： 由 ¬ C 得 ¬ C ∨ ¬ D (Add) → ¬(C ∧ D) (DeM) → A ∧ B (DS) → A (Simp)。
  • 解法二（利用 Dist 分配律）： 直接展開為 [(A ∧ B) ∨ C] ∧ [(A ∧ B) ∨ D] (Dist) → (A ∧ B) ∨ C (Simp) → A ∧ B (DS) → A (Simp)。

第五單元：條件證明 (CP) 與 間接證明 (IP) 證明定理（小考 6）

經典定理：⊢ A → (¬ A → B)（假前項保證條件句恆真）

  • 解法一（嵌套 CP）：假設 A，再假設 ¬ A，由 ¬ A ∨ B (Add) 與 ¬ A 行 DS 得 B，消去得 ¬ A → B，再消去得全句。
  • 解法二（IP 歸謬法）：假設否定式 ¬[A → (¬ A → B)]，展開為 A ∧ (¬ A ∧ ¬ B)，提取 A ∧ ¬ A 矛盾式，由 IP 解除假設。
  • 解法三（DN + Impl 極速代數法）：由假設 A 得 ¬¬ A，加項 ¬¬ A ∨ B (Add)，化為 ¬ A → B (Impl)，消去 AP 即得定理。

第六單元：語句邏輯十大核心觀念單選避坑指南（小考 7）

肯定後項的謬誤 (Affirming the Consequent)

肯定後項的謬誤是一種經典的命題邏輯形式謬誤。其推論外表與合法的假言推理_Modus_Ponens極為相似，但推論形式本質上是無效的 (Invalid)。

1. 形式架構

  • 謬誤形式：
\begin{aligned} & P → Q
& Q
\hline \therefore\ & P (錯誤推論！) \end{aligned}
  • 核心盲點：條件句只斷定「若 P 則 Q」（P 是 Q 的充分條件），但並沒有斷定「只有 P 才會 Q」（P 不一定是 Q 的必要條件）。肯定了後項 Q，並不能反推出前項 P 必定成立。

2. 講義經典反例剖析 (pp. 8-9)

2.1 閱讀與清醒案例 (前提結論皆真，但形式無效)

  1. 如果你正在讀這本書，那麼你沒有睡著。(P → Q，真)
  2. 你現在沒有睡著。(Q，真)
    \therefore 3. 你正在讀這本書。(P，可能為真，但並非邏輯必然)
  • 分析：你沒睡著可能是在滑手機、散步或看電影。即使前提與結論事實上碰巧皆為真，此論證形式依然是無效的。

2.2 羅德島案例 (前提皆真，結論假 → 絕對無效！)

  1. 如果羅德島是南太平洋的一個小島，那麼它比德州小。(P → Q，真，因為假前項蘊涵真條件句)
  2. 羅德島比德州小。(Q，真)
    \therefore 3. 羅德島是南太平洋的一個小島。(P，假！)
  • 分析：此例完美構造了「前提全真而結論為假」的反例，徹底證偽了此形式的有效性。

2.3 鴨嘴獸案例 (前提有假，結論真)

  1. 如果鴨嘴獸是哺乳動物，則鴨嘴獸不下蛋。(P → Q，假)
  2. 鴨嘴獸不下蛋。(假，事實上鴨嘴獸是卵生哺乳類)
    \therefore 3. 鴨嘴獸是哺乳動物。(真)
  • 分析：再次展示了無效論證形式在真假值上的不可預測性。

2.4 雙簧管樂器案例

  1. 如果雙簧管是銅管樂器，那麼有些銅管樂器是用雙簧片演奏的。(真)
  2. 有些銅管樂器是用雙簧片演奏的。(假)
    \therefore 3. 雙簧管是銅管樂器。(假)

引進與消去規則系統 (Introduction & Elimination System)

除了 18 條規則＋CP/IP 的系統外，邏輯學家根岑（Gerhard Gentzen）提出了另一種更為對稱且結構簡潔的自然演繹系統：針對每一個邏輯連接詞各設立一條引進規則 (Introduction) 與一條消去規則 (Elimination)，外加一條重複規則 (Reiteration)，共 11 條規則。

1. 11 條 Int-Elim 規則對照表

連接詞 引進規則 (Introduction, I) 消去規則 (Elimination, E) 傳統 18 條系統對應
連言 (∧ 或 ·) ∧ I：p,\ q ⊢ p ∧ q ∧ E：p ∧ q ⊢ p 或 q Conj 與 Simp
選言 (∨) ∨ I：p ⊢ p ∨ q 或 q ∨ p ∨ E：p ∨ q,\ ¬ p ⊢ q Add 與 DS

雙條件句 (↔ 或 ≡) ↔ I：p → q,\ q → p ⊢ p ↔ q ↔ E：p ↔ q ⊢ p → q 或 q → p Equiv 與 Simp

    • 將較不直覺的假設證明法（→ I, ¬ I）設為初始核心規則。

條件證明法 (Conditional Proof, CP)

條件證明法 (CP) 是自然演繹法中用於推導條件句（P → Q）的強大證明技術。它藉由引入「暫時性假設」，突破了 18 條規則系統無法證明恆真句與特定有效論證的限制。

1. 核心推導理念

若欲證明結論形如 P → Q：

  1. 設定假設前提 (Assumed Premise, AP)：暫時假定前件 P 為真。
  2. 在假設子作用域內推導：結合已知前提與 P，逐步導出後件 Q。
  3. 解除假設 (Discharge)：一旦導出 Q，便關閉假設區間，正式斷定：若 P 成立，則 Q 必成立，即得到 P → Q。

2. 標準排版格式與作用域封閉線

前提：
1. A -> B                      (前提)
2. B -> C                      (前提)  /∴ A -> C

證明步驟：
3. | A                         (AP，假設前件，求證 C)
4. | B                         (1, 3 MP)
5. | C                         (2, 4 MP)
6. A -> C                      (3-5 CP，消去假設)
Q.E.D.

3. 使用 CP 的四大嚴格鐵律

[!CAUTION]

  1. 作用域隔離原則：封閉線（直線區間）內由 AP 所推出的任何步驟，在封閉線關閉後，絕對不可被封閉線外的後續步驟單獨引用！
  2. 所有假設必須全數解除：證明完畢時，不可殘留任何未被 CP 或 IP 消去的 AP。
  3. 封閉線不可交叉重疊：多重假設可以巢狀 (Nested) 逐層包覆，或在完成一個 CP 後並列開啟另一個 CP，但絕不可錯位交叉。
  4. 結論形式約束：CP 解除假設後所得出的那一列，其結構必然是以該 AP 為前件的條件句。

4. 巢狀 CP (Nested CP) 示範

欲證明：C → D ⊢ A → [B → (C → D)]

1. C -> D                      (前提)  /∴ A -> [B -> (C -> D)]
2. | A                         (AP 1)
3. | | B                       (AP 2)
4. | | | C                     (AP 3)
5. | | | D                     (1, 4 MP)
6. | | C -> D                  (4-5 CP)
7. | B -> (C -> D)             (3-6 CP)
8. A -> [B -> (C -> D)]        (2-7 CP)

真值表判定法 (Truth Table Method)

真值表法是語句邏輯中最經典且完備的機械決定程序 (Decision Procedure)。它能以有限步驟精確判定任何語句的真值性質、論證有效性以及語句集合的一致性。

1. 完整真值表之五步建構步調 (Walk-Through)

依據課本第 63-65 頁規範，構作真值表的標準算法如下：

  1. 第一步：決定總行數：
    • 由該語句式的一對一邏輯形式所包含的相異變元數 n 決定，總行數固定為 2n：
      • 1 個變元 ⟹ 21 = 2 行
      • 2 個變元 ⟹ 22 = 4 行
      • 3 個變元 ⟹ 23 = 8 行
      • 4 個變元 ⟹ 24 = 16 行
  2. 第二步：由右至左系統化指派真值：
    • 最右側變元欄：每 1 行交替一次真值（T, F, T, F, T, F …）。
    • 往左第 2 個變元欄：每 2 行交替一次真值（T, T, F, F, T, T, F, F …）。
    • 往左第 3 個變元欄：每 4 行交替一次真值（T, T, T, T, F, F, F, F …）。
    • 往左第 k 個變元欄：每 2k-1 行交替一次真值。
  3. 第三步：將變元基礎真值複製至公式下方對應欄位。
  4. 第四步：由內向外計算子複合項：
    • 優先計算最小作用域的否定號（∼）。
    • 逐步向外計算括弧內部的二元連接詞（·, ∨, ⊃, ≡）。
  5. 第五步：計算主連接詞 (Main Connective) 獲得最終結論欄。

2. 判定有效性與一致性

2.1 判定論證有效性

  • 判準：檢查是否存在**「前提皆為真，但結論卻為假」**的反例列（Counterexample row）。
    • 若不存在任何反例列 ⟹ 論證是形式有效 (Valid) 的。
    • 若存在至少一列反例 ⟹ 論證是形式無效 (Invalid) 的。

2.2 判定集合一致性 (Consistency)

  • 判準：檢查是否存在至少一列使得集合中所有語句同時為真。
    • 若存在至少一列同真 ⟹ 集合為一致 (Consistent / Satisfiable)。
    • 若所有列皆不可能同真 ⟹ 集合為不一致 (Inconsistent)。

3. 短真值表法 / 歸謬賦值法 (Short Truth Table Test)

當變元達到 3 到 5 個時，完整真值表（8 到 32 行）極為繁複。此時使用短真值表法進行快速證偽：

  1. 假設反例存在：強制設定結論為假 (F)，且所有前提皆為真 (T)。
  2. 反向賦值推導：依據真值條件逆推各變元。
  3. 裁決結論：
    • 若成功賦值且無衝突 ⟹ 成功抓到反例，論證無效！
    • 若必然爆發矛盾 ⟹ 反例在邏輯上不可能存在，反證論證有效！

自然演繹法 (Natural Deduction)

自然演繹法是現代符號邏輯中最核心的語法推導系統。相較於真值表法，自然演繹法能避免指數級膨脹的真值列，並精準模擬人類合理的推論步調。

1. 兩大規則體系之根本區別 (Implication vs. Replacement)

自然演繹系統由 8 條單向推論規則 與 10 條雙向等值規則 構成，兩者在使用權限上有極其嚴格的劃分：

比較維度 8 條蘊涵推論規則 (Rules of Inference) 10 條等值置換規則 (Rules of Replacement)
推論方向 單向推導 (⊢)：只能由前提推導結論，不可反推。 雙向等值 (::)：左右式完全等價，可互換。
作用範圍 只能運用於「整列語句（Whole line）」！ 可運用於「局部子句（Any subformula）」！
代表規則 MP, MT, DS, HS, Simp, Conj, Add, CD DN, DeM, Comm, Assoc, Dist, Contra, Impl, Exp, Taut, Equiv

[!CAUTION] 致命禁忌：絕不可將單向推論規則應用於語句的區域性子句！例如：

  • 從 (A ∧ B) ∨ C 試圖用 Simp 推導出 A ∨ C 是完全無效的錯誤推論！
  • 只有等值規則（如 DeM）才能在括弧內外自由進行局部替換。

2. 自然演繹 18 條核心規則總覽

2.1 8 條單向推論規則 (Implicational Rules)

  1. MP (Modus Ponens)：p → q,\ p ⊢ q
  2. MT (Modus Tollens)：p → q,\ ¬ q ⊢ ¬ p
  3. DS (Disjunctive Syllogism)：p ∨ q,\ ¬ p ⊢ q（或否定 q 導出 p）
  4. HS (Hypothetical Syllogism)：p → q,\ q → r ⊢ p → r
  5. Simp (Simplification)：p ∧ q ⊢ p（或導出 q）
  6. Conj (Conjunction)：p,\ q ⊢ p ∧ q
  7. Add (Addition)：p ⊢ p ∨ q
  8. CD (Constructive Dilemma)：p ∨ q,\ p → r,\ q → s ⊢ r ∨ s

2.2 10 條雙向等值規則 (Replacement Rules)

  1. DN (Double Negation)：p :: ¬¬ p
  2. DeM (DeMorgan's Theorem)：¬(p ∧ q) :: ¬ p ∨ ¬ q；¬(p ∨ q) :: ¬ p ∧ ¬ q
  3. Comm (Commutation)：p ∨ q :: q ∨ p；p ∧ q :: q ∧ p
  4. Assoc (Association)：p ∨ (q ∨ r) :: (p ∨ q) ∨ r；p ∧ (q ∧ r) :: (p ∧ q) ∧ r
  5. Dist (Distribution)：p ∧ (q ∨ r) :: (p ∧ q) ∨ (p ∧ r)；p ∨ (q ∧ r) :: (p ∨ q) ∧ (p ∨ r)
  6. Contra (Contraposition)：p → q :: ¬ q → ¬ p
  7. Impl (Material Implication)：p → q :: ¬ p ∨ q
  8. Exp (Exportation)：(p ∧ q) → r :: p → (q → r)
  9. Taut (Tautology)：p :: p ∧ p；p :: p ∨ p
  10. Equiv (Equivalence)：p ↔ q :: (p → q) ∧ (q → p)；p ↔ q :: (p ∧ q) ∨ (¬ p ∧ ¬ q)

3. 六大證明解題戰略心法 (Proof Strategies)

  1. 結構模式匹配：留心重覆出現的子句，優先思考能否運用 MP, MT, DS, HS。
  2. 善用短小語句：短句是最佳推論槓桿，若能由前提推出單一字元短句，務必儘快導出。
  3. 從結論逆向倒推 (Work Backward)：檢視結論的主連接詞：
    • 結論若為條件句，優先考慮用 CP 或 HS 倒推。
    • 結論若為連言，分別推導兩個連言肢再用 Conj。
  4. 引入新訊息：若結論中出現前提完全沒有的新原子語句，必須大膽使用 Add 規則引進。
  5. 消去多餘中間項：若某語句僅出現一次且結論中不需要它，通常是多餘的，設法運用 HS、Dist 或 Simp 割離。
  6. 選言與條件互化：遇到條件句與選言混雜無從著手時，使用 Impl 統一其邏輯結構。

4. 進階推論方法（完備性所必需）

單靠 18 條規則無法證明零前提定理（如恆真句），為達成系統的完備性，必須擴充：

  • 條件證明法 (CP)：針對條件句假設前件推導後件。
  • 間接證明法 (IP)：歸謬法，假設否定式推導矛盾。
  • 簡化替代系統：引進與消去規則系統（Gentzen 風格 11 條規則）。

述詞邏輯演繹證明法 (Predicate Deduction)

述詞邏輯證明法將語句邏輯的自然演繹體系擴展至量化命題，形成一套能夠精確推導個體與性質內在結構的強大工具。

1. 完整規則庫組成結構

述詞邏輯的演繹證明建立在三大規則支柱上：

  1. 語句邏輯 18 條規則 ＋ CP ＋ IP（完全繼承）。
  2. 量詞推論四規則：UI, UG, EI, EG。
  3. 量詞等值規則：量詞否定規則_QN。
  4. 等同專用規則（若論證涉及等號）：ID 與 IR。

2. 標準三階段解題戰略流程

flowchart LR
    A["第一階段：剝離量詞<br>(Strip Quantifiers)"] --> B["第二階段：命題演算<br>(Sentential Logic Proof)"] --> C["第三階段：重建量化<br>(Re-quantify)"]

階段一：消去量詞 (Strip Quantifiers)

  1. 先用 QN 打開所有否定量詞：若看到 ¬(x) 或 ¬(∃ x)，第一時間用 QN 轉化為正向形式。
  2. 「先做 EI，再做 UI！」（鐵律）：
    • 若前提中同時存在全稱語句與存在語句，必須優先對存在語句做 EI，引進全新準變元（例如 x）。
    • 隨後，再對全稱語句做 UI，主動挑選同一個變元 x 進行代換，使兩者能在命題演算階段完美相遇！

階段二：命題演算推導 (Sentential Proof)

  • 利用 MP, MT, HS, DS, DeM, Simp, Conj 等經典規則，在個體層次推導出目標性質。

階段三：添加量詞 (Re-quantify)

  1. 若結論是全稱句：檢查推導出的變元是否符合 UG 的 3 項嚴格限制（未被常元污染、非 EI 引進、不在未解除 AP 中），合法使用 UG。
  2. 若結論是存在句：直接合法使用 EG。

3. 典型例題逐步示範

題目：證明 (x)(Ax → Bx),\ (∃ x)Ax ⊢ (∃ x)Bx

前提：
1. (x)(Ax -> Bx)               (前提，全稱句)
2. (∃x)Ax                      (前提，存在句)  /∴ (∃x)Bx

證明步驟：
3. Ax                          (2 EI，★先做 EI，引進全新準變元 x)
4. Ax -> Bx                    (1 UI，★後做 UI，配合挑選 x)
5. Bx                          (3, 4 MP，命題演繹推導)
6. (∃x)Bx                      (5 EG，添加存在量詞)
Q.E.D.

間接證明法 (Indirect Proof, IP / 歸謬法)

間接證明法 (IP)，又稱反證法或歸謬法 (Reductio ad Absurdum)，是邏輯與哲學論辯中最古老而強大的證明策略。

1. 核心理念與數學原理

演繹論證具有保真性（不可能從真前提推導出假結論）。因此：

  • 若欲證明目標語句 P：
    1. 假設其否定為真 (AP)：假定 ¬ P（若待證為 ¬ P，則假定 P）。
    2. 在該假設下推導出矛盾式：導出形式為 Q ∧ ¬ Q（或 ⊥）的矛盾語句。
    3. 解除假設：矛盾不可能為真，而原已知前提皆假定為真，故產生矛盾的唯一原因必然是暫時假設了 ¬ P。因此消去假設，斷定 P 為真！

2. 標準格式示範

前提：
1. A -> B                      (前提)
2. B -> C                      (前提)
3. A                           (前提)  /∴ C

證明步驟：
4. | ~C                        (AP，假設結論為假，求證矛盾)
5. | A -> C                    (1, 2 HS)
6. | C                         (3, 5 MP)
7. | C · ~C                    (4, 6 Conj，導出矛盾！)
8. C                           (4-7 IP，解除假設)
Q.E.D.

3. 爆炸原理與 CP/IP 互導定理

3.1 爆炸原理 (Principle of Explosion: Ex Falso Quodlibet)

在經典邏輯中，從矛盾句可以合法推導出任何任意語句：

B ∧ ¬ B ⊢ X

推導過程只需四步：

  1. B ∧ ¬ B
  2. B (1 Simp)
  3. B ∨ X (2 Add)
  4. ¬ B (1 Simp)
  5. X (3, 4 DS)

3.2 IP 與 CP 互為導出規則

  • 利用上述爆炸原理與 CP 規則，可以完全導出 IP 規則；反之，利用 IP 亦可完全導出 CP。
  • 因此在後設邏輯中，自然演繹系統只要在 18 條規則外加入 CP 或 IP 兩者之一，系統即滿足完備性。

4. 戰略建議

  • 不要一開始就用 IP：IP 往往需要將複合語句徹底打碎以尋找矛盾，有時會讓推導反而變長。
  • 何時最適合使用 IP？
    • 當結論非常短（例如單一原子語句 A 或否定句 ¬ A），直接推導缺乏著力點時，利用 IP 可以多獲得一個好用的假設短前提！

述詞邏輯 55 條定理總覽與分類體系 (55 Predicate Theorems)

參考來源：林正弘《邏輯》附錄二；課本 Exercise 10-12 核心定理集合。

一階述詞邏輯擁有極為豐富的定理體系。這 55 條定理精確揭示了全稱量詞 ((x))、存在量詞 ((∃ x)) 與各邏輯連接詞之間的代數運算規律。

一、 量詞對「條件句」的分配與蘊涵規律 (Q1, Q2, Q3, Q7, Q8)

定理編號 定理公式 性質 重要警示與反命題證偽
Q1 (x)(Fx → Gx) → [(x)Fx → (x)Gx] 單向蘊涵 反之不然！ 即使所有人是人蘊涵所有人會死，不代表「若所有人是偶數則所有人是質數」能反推前提。
Q2 (x)(Fx → Gx) → [(∃ x)Fx → (∃ x)Gx] 單向蘊涵 反之不然！
Q3 (x)(Fx ∨ Gx) ≡ [(∃ x)¬ Fx → (x)Gx] 雙向等值 連結選言量化與條件量化。
Q7 [(x)Fx → (∃ x)Gx] ≡ (∃ x)(Fx → Gx) 雙向等值 全稱蘊涵存在等價於存在條件句。
Q8 [(∃ x)Fx → (x)Gx] → (x)(Fx → Gx) 單向蘊涵 反之不然！

二、 量詞對「連言」與「選言」的分配律 (Q4, Q5, Q6, Q9, Q10)

量詞在連言 (∧) 與選言 (∨) 的分配上呈現出鮮明的不對稱美感：

  1. 全稱量詞完全分配於連言 (Q4)：
(x)(Fx ∧ Gx) ≡ [(x)Fx ∧ (x)Gx]
  1. 全稱量詞對選言「僅具單向性」(Q5)：
[(x)Fx ∨ (x)Gx] → (x)(Fx ∨ Gx) （反之不然！）
  • 反例：所有整數要麼是奇數要麼是偶數 (x)(Ox ∨ Ex) 是真話；但「所有整數都是奇數，或者所有整數都是偶數」顯然為假。
  1. 存在量詞完全分配於選言 (Q10)：
(∃ x)(Fx ∨ Gx) ≡ [(∃ x)Fx ∨ (∃ x)Gx]
  1. 存在量詞對連言「僅具單向性」(Q6)：
(∃ x)(Fx ∧ Gx) → [(∃ x)Fx ∧ (∃ x)Gx] （反之不然！）
  • 反例：世上有活人 (∃ x)Ax，世上也有死人 (∃ x)Bx；但世上不存在「既活著又死透的人」(∃ x)(Ax ∧ Bx)。

三、 獨立命題 P 之量詞前綴移位定理 (Q11 ~ Q22)

當複合句的某個成分命題 P 不含有自由變元 x 時，量詞可以自由跨越括弧：

句型結構 前綴移位等值式 備註說明
連言 / 選言 (x)(P ∧ Gx) ≡ P ∧ (x)Gx (Q11)
(∃ x)(P ∨ Gx) ≡ P ∨ (∃ x)Gx (Q14)		 量詞移位時符號保持不變。
條件句後件 (x)(P → Gx) ≡ P → (x)Gx (Q15)
(∃ x)(P → Gx) ≡ P → (∃ x)Gx (Q16)		 後件移位，量詞保持不變。
條件句前件 (x)(Fx → P) ≡ [(∃ x)Fx → P] (Q17)
(∃ x)(Fx → P) ≡ [(x)Fx → P] (Q18)		 前件移位，量詞發生顛倒對偶！
全稱變存在，存在變全稱。

四、 多重量詞交換律與不可逆不對稱性 (Q34 ~ Q55)

處理多重量詞關係（Relational Predicates）時的最核心法則：

1. 同種量詞可自由交換 (Q36, Q37)

(x)(y)Fxy ≡ (y)(x)Fxy (∃ x)(∃ y)Fxy ≡ (∃ y)(∃ x)Fxy

2. 異種量詞的「不可逆單向傳導」(Q38, Q39)

(∃ x)(y)Fxy → (y)(∃ x)Fxy （成立，但反向絕對無效！）

哲學與常識經典辨析：

  • 前項 (∃ x)(y)Fxy：「存在一個人 x，所有人都愛他。」（超級萬人迷）。
  • 後項 (y)(∃ x)Fxy：「每個人 y，都有某個他所愛的人 x。」（人皆有愛）。
  • 顯然，有超級萬人迷存在可以推出人皆有愛；但由人皆有愛，絕不能反推世上存在一位被所有人共同深愛著的萬人迷！

一、 邏輯學的本質與論證基礎 (Foundations of Logic & Argument)

  • 論證的基本要素：
    • 論證與陳述句：論證結構（前提、結論與推論關係 \therefore）、指示詞、語句與陳述句之真假值、因果說明 (Explanation) vs. 理由證成 (Justification)。
    • 發現脈絡與證成脈絡：區分概念產生的因果歷史（發現脈絡）與理性辯護的邏輯檢驗（證成脈絡，邏輯學的核心使命）。
    • 使用與提及_Use_and_Mention：談論世界 (Use) vs. 談論符號 (Mention)、對象語言 vs. 後設語言。
  • 推論的兩大類型：
    • 演繹與歸納：演繹的嚴格保真性（必然性）vs. 歸納的經驗擴展性（蓋然性與機率強度）。
  • 演繹論證的核心評價標準：
    • 有效性與健全性：形式保真，不可能前提皆真而結論為假。真值與有效性 4 象限矩陣；健全性 = 有效性 ＋ 前提全真。
    • 一致性與有效性檢測：陳述句集合的一致性；基本定理：論證有效 ⟺ {前提} ∪ {¬結論} 是不一致的。

二、 語句邏輯 (Sentential / Propositional Logic)

1. 語法學 (Syntax)

  • 語句形式與取代實例：常元 vs. 變元、一對一邏輯形式 (One-One Logical Form)、取代實例兩大鐵律、適真句裁決定理。
  • 自然語言翻譯與充要條件：充分條件 (If) vs. 必要條件 (Only if)、Unless、Not both vs. Neither nor。
  • 實質條件句的哲學爭論與證成：前件為假時定為真的三大理由（一致性、簡單性、保全 MP）、反事實條件句辨析。
  • 自然語言否定深層語意_部分否定與雙重否定：部分否定 (Not all) vs. 全部否定 (None) 語義剖析、雙重否定轉化。

  • 真值表判定法：五步標準建構步調（2n 行數與由右向左交替指派）、短真值表快速反例檢驗、真值表的理論證成。

    • 10 條雙向等值規則（局部適用）：DN、DeM、Comm, Assoc, Dist、Contra & Impl、Exp & Taut、Equiv。

4. 後設邏輯 (Metatheory)

假言三段論 (Hypothetical Syllogism, HS)

假言三段論 (HS) 是自然演繹法_Natural_Deduction中用於串聯條件句的單向推論規則，體現了條件蘊涵關係的遞移性 (Transitivity)。

1. 形式定義

  • 句法形式：
\begin{aligned} & p → q
& q → r
\hline \therefore\ & p → r \end{aligned}
  • 規則表述：給定兩個條件句，若第一個條件句的後項與第二個條件句的前項相同（居間媒介項 q），則可合法推導出由第一個條件句的前項指向第二個條件句後項的新條件句。

  • 限制：HS 屬於單向推論規則，只能運用於整列語句，絕不可應用於括弧內部的子句。

假言推理 (Modus Ponens, MP)

假言推理（拉丁語：Modus Ponens，字面意思為「藉由肯定而肯定的模式」），簡稱 MP，是命題邏輯與自然演繹法_Natural_Deduction中最基本且直觀的推論規則。

1. 形式定義

  • 句法形式：
\begin{aligned} & P → Q
& P
\hline \therefore\ & Q \end{aligned}
  • 規則表述：若給定一個條件句（若 P 則 Q），且同時給定該條件句的前項 P，則可合法推導出其後項 Q。

2. 語意保真證明 (真值表)

P Q P → Q (前提1) P (前提2) Q (結論)
T T T T T（有效列）
T F F T F
F T T F T
F F T F F

在所有前提均為真（第一列）的情況下，結論 Q 必然為真。因此形式保證有效 (Valid)。

3. 常見謬誤警訊

  • 禁止逆用：由 P → Q 與 Q 不能推導出 P！
    • 犯此錯誤稱為：肯定後項的謬誤（形式謬誤）。

分配律 (Dist)、結合律 (Assoc) 與 交換律 (Comm)

這三組規則奠定了語句邏輯運算子的代數結構，賦予我們重構命題括弧、次序與結合方式的完全自由。

1. 交換律 (Commutation, Comm)

  • 形式：
\begin{aligned} p ∨ q &:: q ∨ p
p ∧ q &:: q ∧ p \end{aligned}
  • 注意禁忌：條件句不具交換律（p → q 絕不等於 q → p）！

2. 結合律 (Association, Assoc)

  • 形式：
\begin{aligned} p ∨ (q ∨ r) &:: (p ∨ q) ∨ r
p ∧ (q ∧ r) &:: (p ∧ q) ∧ r \end{aligned}
  • 限制：只有在連詞完全相同（全為選言，或全為連言）時才能移動括弧。不可從 A ∨ (B ∧ C) 移動括弧為 (A ∨ B) ∧ C！

3. 分配律 (Distribution, Dist)

  • 形式：
\begin{aligned} p ∧ (q ∨ r) &:: (p ∧ q) ∨ (p ∧ r)
p ∨ (q ∧ r) &:: (p ∨ q) ∧ (p ∨ r) \end{aligned}
  • 解題核心價值：
    • 割離不要項：在推導中，若語句中混雜著不需要的中間變元，透過 Dist 可以把原句拆開，再用 Simp 將不要的項徹底分離剔除！

否定後項 (Modus Tollens, MT)

否定後項（拉丁語：Modus Tollens，字面意思為「藉由否定而否定的模式」），簡稱 MT，是自然演繹法中用於條件句反向推導的核心規則。

1. 形式定義

  • 句法形式：
\begin{aligned} & P → Q
& ¬ Q
\hline \therefore\ & ¬ P \end{aligned}
  • 規則表述：若給定一個條件句（若 P 則 Q），且給定該條件句後項的否定 ¬ Q，則可合法推導出前項的否定 ¬ P。

2. 哲學與科學方法意涵

  • 卡爾·波普爾（Karl Popper）的否證論 (Falsificationism) 即奠基於 Modus Tollens：
    • 假說 H 蘊涵觀察預測 O（H → O）。
    • 實驗觀察到了 ¬ O。
    • 因此假說被駁斥：¬ H。

3. 常見謬誤警訊

  • 禁止逆用：由 P → Q 與 ¬ P，不能推導出 ¬ Q！
    • 犯此錯誤稱為：否定前項的謬誤 (Denying the Antecedent)。

實質等值律 (Material Equivalence, Equiv)

實質等值律 (Equiv) 是自然演繹法中解構雙條件句（↔ 或 ≡）的核心雙向規則。

1. 形式定義

  • 雙向條件式拆解：
p ↔ q :: (p → q) ∧ (q → p)
  • 真值同況拆解：
p ↔ q :: (p ∧ q) ∨ (¬ p ∧ ¬ q)

2. 戰略價值

  • 打破雙條件句：在自然演繹中，原生的推論規則（如 MP, MT）無法直接作用於雙條件句。透過 Equiv，可將 p ↔ q 化為 (p → q) ∧ (q → p)，再用 Simp 分離出單向條件句進行後續推導。
  • 建構雙條件句結論：若結論要求證明 A ↔ B，標準策略為分別證明 A → B 與 B → A，利用 Conj 合併後，透過 Equiv 完成最後一步。

實質蘊涵律 (Impl) 與 異質換位 (Contra)

在自然演繹法中，實質蘊涵律 (Impl) 與 異質換位律 (Contra) 是處理條件句（→）時不可或缺的兩大雙向等值工具。

  • 形式：
p → q :: ¬ p ∨ q
  • 語意本質：「若 p 則 q」在真值函應上的極小意義，即「不可能前真後假」（¬(p ∧ ¬ q)），由笛摩根定律轉化即為「要麼前件為假，要麼後件為真」（¬ p ∨ q）。
  • 戰略樞紐地位：
    • 連接條件句與選言的唯一雙向橋樑。
    • 當推論過程中條件句與選言語句雜陳、無法套用 MP/MT/DS 時，使用 Impl 能將兩者結構統一。

2. 異質換位律 (Contraposition, Contra)

  • 形式：
p → q :: ¬ q → ¬ p
  • 語意本質：逆否命題與原條件句完全等值。
  • 戰略價值：
    • 調整條件句前件與後件的位置，便於與其他前提進行HS串聯。
    • 搭配否定符號調整目標結論。

笛摩根定律 (DeMorgan's Laws, DeM)

笛摩根定律 (DeM) 是邏輯學與集合論中最核心的對偶等值規則，精準揭示了「否定」、「連言」與「選言」三者之間的轉化關係。

1. 形式定義 (雙向等值 ::)

\begin{aligned} ¬(p ∧ q) &:: ¬ p ∨ ¬ q
¬(p ∨ q) &:: ¬ p ∧ ¬ q \end{aligned}
  • 規則 1：「不會既 p 又 q」邏輯等值於「要麼非 p，要麼非 q」。
  • 規則 2：「既不是 p 也不是 q」邏輯等值於「非 p 且 非 q」。

2. 局部替換特徵

作為 10 條等值置換規則之一，DeM 不僅能用於整列語句，更可直接應用於任何複雜句式的內部子成分。例如：

[(A ∧ B) → C] ⟺ [(¬ A ∨ ¬ B) → C]

3. 解題戰略價值

  • 拆解複合否定句：當看到括弧前面帶有否定符號（如 ¬(P ∧ Q) 或 ¬(P ∨ Q)）時，通常應第一時間使用 DeM 將括弧打開，以便將長句化成短句進行 Simp 或 DS。

等同規則 (ID) 與 反身律 (IR)

當述詞邏輯擴展至包含等號「=」的一階等同邏輯（First-Order Logic with Identity）時，系統引入兩條專屬的核心公理與規則。

1. 等同規則 (Rule of Identity, ID / 萊布尼茲不可區分之同一性律)

1.1 形式定義

\begin{aligned} & ϕ(u)
& u = w (或 w = u)
\hline \therefore\ & ϕ(w) \end{aligned}

其中 u, w 為任意個體常元或變元，ϕ(w) 是用 w 替換 ϕ(u) 中自由出現的 u 所得之結果。

1.2 哲學本質

  • 相同事物的可替換性 (Substitutivity of Identicals)：若兩名稱指向同一個實體（例如「金庸」=「查良鏞」），則任何關於金庸的客觀真陳述，在將名稱代換為查良鏞後，其真值保證完全不變。

2. 等同反身律 (Identity Reflexivity, IR)

2.1 形式定義

⊢ (x)(x = x)

在證明的任何步驟中，均可直接引入零前提公理：(x)(x = x)。

2.2 為什麼需要 IR？

在某些涉及等同的有效論證中（例如 (x)[(x = a) → Fx] ⊢ Fa），若缺少 IR，證明將陷入僵局，系統將不完備：

1. (x)[(x = a) -> Fx]          (前提)  /∴ Fa
2. (a = a) -> Fa               (1 UI)
3. (x)(x = x)                  (IR，引入反身公理)
4. a = a                       (3 UI)
5. Fa                          (2, 4 MP)
Q.E.D.

簡化律 (Simp) 與 連言律 (Conj) 是自然演繹法_Natural_Deduction中處理連言語句（p ∧ q）的兩大基礎推論規則。

1. 形式定義

1.1 簡化律 (Simplification, Simp)

  • 形式：
p ∧ q ⊢ p 或 p ∧ q ⊢ q
  • 語意：既然連言為真要求兩者皆真，則單獨抽取其中任一個連言肢必然為真。
  • 嚴格禁忌：只能對整列語句使用！絕不可對複合句中的子連言進行簡化（例如從 (A ∧ B) ∨ C 簡化出 A ∨ C 是無效推論）。

1.2 連言律 (Conjunction, Conj)

  • 形式：
\begin{aligned} & p
& q
\hline \therefore\ & p ∧ q \end{aligned}
  • 語意：若兩個語句各自已在證明中被確立為真，則將兩者以「∧」結合的複句亦必然為真。

輸出入律 (Exp) 與 重言律 (Taut) 是自然演繹證明中處理多重條件與化簡重複項的利器。

  • 形式：
(p ∧ q) → r :: p → (q → r)
  • 語意：「若 p 且 q 同時成立則 r」等價於「若 p 成立，則只要 q 成立便會得到 r」。
  • 戰略價值：

  • 戰略價值：
    • 消去重複累贅：例如由推導得出 A ∨ A，套用 Taut 即可直接化簡為單一語句 A。

選言三段論 (Disjunctive Syllogism, DS)

選言三段論（Disjunctive Syllogism，簡稱 DS），又稱析取三段論，是自然演繹法_Natural_Deduction中處理選言語句（P ∨ Q）的核心推論規則。

1. 形式定義

  • 句法形式 1：
\begin{aligned} & P ∨ Q
& ¬ P
\hline \therefore\ & Q \end{aligned}
  • 句法形式 2：
\begin{aligned} & P ∨ Q
& ¬ Q
\hline \therefore\ & P \end{aligned}
  • 規則表述：若給定一個選言語句（P 或 Q），且否定了其中一個選言肢，則可以合法推導出另一個選言肢必然為真。

2. 講義經典範例

範例 1：小明的居住地 (Example A)

  1. 小明是新竹人，或者小明是台北人。(P ∨ Q)
  2. 並非小明是新竹人。(¬ P) \therefore 3. 小明是台北人。(Q)
  • 分析：此論證形式完全有效，無論我們實際上是否知道小明的戶籍事實。

範例 2：天氣預測 (Example B)

  1. 今天會下雨或者今天會下雪。(P ∨ Q)
  2. 並非今天會下雨。(¬ P) \therefore 3. 今天會下雪。(Q)

  1. 十八尖山在新竹，或者陽明山在高雄。(T)
  2. 並非「陽明山在高雄」。(T) \therefore 3. 十八尖山在新竹。(T)
  • 形式符合 DS（有效），且兩前提均為事實真相，因此構成了健全論證 (Sound Argument)。

定理 Q17：前件全稱移出轉為存在

(x)(Fx → P) ⟺ [(∃ x)Fx → P]
  • 自然語言對應：
    • 左式：「對任何人而言，若他動了，橋就會塌。」
    • 右式：「只要有人動了，橋就會塌。」
    • 兩者在邏輯上完全等價！

定理 Q18：前件存在移出轉為全稱

(∃ x)(Fx → P) ⟺ [(x)Fx → P]
  • 自然語言對應：
    • 「如果所有人都動了，橋才會塌。」

後件移入移出（量詞保持不變）

若前件 P 不含自由變元 x：

\begin{aligned} (x)(P → Fx) &⟺ [P → (x)Fx]
(∃ x)(P → Fx) &⟺ [P → (∃ x)Fx] \end{aligned}

量詞推論四規則 (UI, UG, EI, EG) 與 五大限制

在述詞邏輯中，要將語句邏輯的推論規則（如 MP, HS, MT）套用到量化語句上，必須先透過「量詞推論四規則」合法地消去或添加量詞。

1. 四大規則精確句法定義 (Official Specifications)

1.1 全稱引例 (Rule UI: Universal Instantiation)

(u)(… u …) ⊢ (… w …)
  • Provided (限制條件)：
    1. (… w …) 是將 (… u …) 中自由出現的 u 全數代換為 w 所得的結果；
    2. w 可以是常元 (Constant)，也可以是在 (… w …) 中自由出現的變元 (Variable)（不做其他變更）。

1.2 存在引例 (Rule EI: Existential Instantiation)

(∃ u)(… u …) ⊢ (… w …)
  • Provided (限制條件)：
    1. w 絕不能是個體常元 (Constant)！
    2. w 絕不能是證明先前步驟中已經自由出現過的變元（必須是全新的準變元）！
    3. (… w …) 是將自由出現的 u 全數代換為自由變元 w 所得之結果。

1.3 全稱一般化 (Rule UG: Universal Generalization)

(… u …) ⊢ (w)(… w …)
  • Provided (限制條件)：
    1. u 絕不能是個體常元 (Constant)！
    2. u 絕不能在先前由 EI 所得的步驟中自由出現過！
    3. u 絕不能在尚未被消去的假設前提 (AP) 中自由出現過！
    4. (… w …) 是將自由出現的 u 全數代換為自由變元 w 所得之結果，且 (… u …) 中原本未含有額外自由出現的 w。

1.4 存在一般化 (Rule EG: Existential Generalization)

(… u …) ⊢ (∃ w)(… w …)
  • Provided (限制條件)：
    1. (… w …) 是將 (… u …) 中出現的 u（常元或自由變元）至少一處代換為自由變元 w 所得之結果，且 (… u …) 中原本未含有額外自由出現的 w。

2. 五大主要限制 (The Five Major Restrictions)

為了嚴格防止從真前提推導出假結論（維持系統 Soundness），規則設有 5 項不可逾越的鐵律：

(A) 針對存在引例 (EI) 的兩大限制

  1. 限制 1：EI 絕不能引進個體常元（不能從「有人是兇手」直接推得「張三是兇手」）。
  2. 限制 2：EI 引進的準變元必須是「全新的」，絕不能是先前已使用過的符號：
    • 實戰黃金法則：「先做 EI，再做 UI！」（先讓 EI 佔用新變元，UI 再配合選擇相同變元以利後續推導）。

(B) 針對全稱一般化 (UG) 的三大限制

  1. 限制 3：UG 絕不能對「個體常元」做一般化（不能因為阿圖笨就推導出全人類都是笨蛋）。
  2. 限制 4：UG 絕不能對「由 EI 引進的準變元」做一般化（凡在 EI 列自由出現過的變元皆失去任意性）。
  3. 限制 5：UG 絕不能對「尚未消去的假設前提 (AP)」中自由出現的變元做一般化（必須等 CP/IP 將該假設消去後，變元才能在作用域外重獲任意性）。

附加律 (Add) 與 建設性兩難 (CD)

附加律 (Add) 與 建設性兩難 (CD) 是自然演繹推論中極具戰略價值的進階推論規則。

1. 附加律 (Addition, Add)

  • 句法形式：
p ⊢ p ∨ q 或 p ⊢ q ∨ p
  • 語意保真：相容選言只要有一項為真，全句即為真。既然已知 p 為真，附加任何任意語句 q 所構成的選言必定為真。
  • 核心戰略地位：

    「新訊息引進器」：若結論中出現了在任何前提中都完全未曾出現過的全新原子語句，附加律 (Add) 是在演繹系統中合法引進該新變元的唯一合法途徑！

2. 建設性兩難 (Constructive Dilemma, CD)

  • 句法形式：
\begin{aligned} & p ∨ q
& p → r
& q → s
\hline \therefore\ & r ∨ s \end{aligned}
  • 規則特徵：在 18 條規則體系中，CD 是唯一需要消耗三個前提的推論規則。
  • 語意：已知兩條路徑必擇其一（p ∨ q），而第一條路通往 r，第二條路通往 s，故最終必然落入 r 或 s。

實質條件句的哲學悖論與自然語言的語意鴻溝

摘要 (Abstract)

在現代符號邏輯（經典命題邏輯）的奠基過程中，實質條件句（Material Conditional, 記為 P → Q 或 P ⊃ Q）的真值表定義是初學者最感困惑、也是語言哲學史上引發最激烈交鋒的樞紐之一。形式邏輯將條件句嚴格規定為真值函應（Truth-Functional），並由此確立了當前件為假時，整個條件句無條件為真的公理（F → T ≡ T 且 F → F ≡ T）。這項形式規定雖然成功保全了假言推理（Modus Ponens）、析取律（Addition）與條件證法（Conditional Proof）的系統自洽性，卻在面對自然語言的「若……則……」時產生了深邃的語意鴻溝，直接催生了「實質蘊涵悖論」（Paradoxes of Material Implication）。

本文嚴格基於本知識庫中既有的形式邏輯體系與語意分析文獻，系統性爬梳實質條件句的形式證成理由、核心悖論結構、自然語言的抗拒機制（充要條件混淆與反事實條件句破產），並回顧分析哲學歷史上格萊斯（H. P. Grice）的語用學對話涵意辯護與 C. I. 劉易斯（C. I. Lewis）模態進路的應對策略。文末附錄則彙整當代權威文獻，為未來知識庫之擴充標定指引。

一、 緣起：形式化定義與常識直覺的激烈張力

1. 形式語意學的最小定義

在經典語句邏輯中，條件句 P → Q 的真假值被嚴格限制在四列真值表中：

P (前件) Q (後件) P → Q (實質條件句) ¬ P ∨ Q (實質蘊涵等值式)
T T T T
T F F F
F T T T
F F T T

依據此定義，實質條件句在語意上等值於析取命題：

P → Q ≡ ¬ P ∨ Q ≡ ¬(P ∧ ¬ Q)

換言之，「若 P 則 Q」在形式邏輯中的極小語意僅僅是：「不可能前真而後假」。

2. 日常直覺的兩極分化

當此定義被投射回人類自然語言的日常生活場景時，直覺產生了劇烈的撕裂：

  1. 內容不相干之語句（荒謬反直覺）：

    • (a)「如果新竹是一座城市，則沒有最大的偶數。」（前真後真 → 真）
    • (b)「如果有最大的偶數，則新竹是一座城市。」（前假後真 → 真）
    • (c)「如果有最大的偶數，則新竹是一種植物。」（前假後假 → 真） 在日常對話中，若前件與後件缺乏任何因果關聯或理由關聯，常人必然認定語句 (b) 與 (c) 為無稽之談，甚至斷言其為「假」。

  2. 數學與客觀推論之語句（自然符合直覺）：

    • (d)「如果沒有最大的偶數，則沒有最大的自然數。」（前真後真 → 真）
    • (e)「如果 5 是最大的偶數，則 7 不是偶數。」（前假後真 → 真）
    • (f)「如果 5 是最大的偶數，則 6 不是偶數。」（前假後假 → 真） 在數理推導語境中，人們完全能接受：假定一個錯誤的前提（如 5 是最大的偶數），確實能保證推導出合理的推論。這表明反直覺的根源不在於運算符本身，而在於日常語言對**相干性（Relevance）**的深層期待。

二、 形式系統為何必須堅持實質條件句？（三大系統性證成）

邏輯學家之所以甘冒與日常直覺衝突的風險，依然嚴格維持第 3 列（F, T → T）與第 4 列（F, F → T）的賦值，是因為經典演繹系統存在三大不可動搖的基石要求：

1. 真值函應原則 (Principle of Truth-Functionality) 與模型簡單性

  • 真值函應性要求：任何複合語句之真假，必須且只能由其組成成分語句的客觀真值唯一決定。
  • 若主張「當 P 為假時，P → Q 有時為真、有時為假（取決於前後是否有因果關係）」，形式系統將被迫引入主觀信念、因果網絡、時間序列等極其複雜且難以公理化的語意黑洞，使語句形式的代換實例與機械驗證判定法（如真值表法）徹底瓦解。

2. 嚴格保全核心推論規則的有效性 (Preserving Core Inference Rules)

若任意更動第 3 列或第 4 列的真值規定，將導致演繹系統核心推論規則全盤崩潰：

  • 若第 2 列 (T, F) 定為 T： 演繹體系最核心的根基——假言推理 (Modus Ponens, MP) 即刻失效：前提 P → Q 為真、P 為真，結論 Q 卻可為假。
  • 若第 3 列 (F, T) 定為 F： 論證形式 P → Q,\ ¬ P ⊢ ¬ Q 將無法在真值表上被判定為無效，導致嚴重的「否定前項謬誤」被誤判為有效。
  • 若第 4 列 (F, F) 定為 F： 論證形式 P → Q,\ ¬ P ⊢ Q 同樣將無法被判定為無效。

3. 自然演繹法之「附加律 (Add)」與「條件證明法 (CP)」的聯立約束

在自然演繹法中，若我們接受附加律（Q ⊢ ¬ P ∨ Q）與實質蘊涵等值律（¬ P ∨ Q ≡ P → Q），則我們必然可推導出：

  1. 假定後件 Q 為真；
  2. 根據附加律 (Add)，可得 ¬ P ∨ Q 為真；
  3. 根據實質蘊涵律 (Impl)，可得 P → Q 為真。 這意味著：只要 Q 為真，無論 P 是真是假，P → Q 都必然為真。此外，演繹定理（Deduction Theorem: Γ, A ⊢ B ⟺ Γ ⊢ A → B）更保證了「凡是由假定能有效導出結論者，皆可轉寫為條件句」。

三、 實質蘊涵的經典悖論 (The Paradoxes of Material Implication)

當實質條件句的純粹真值函應形式確立後，便在哲學上誘發了著名的兩大經典悖論：

1. 假前項悖論：¬ P ⊢ P → Q

  • 形式意涵：一個假命題可以實質蘊涵任何命題（拉丁格言：Ex falso quodlibet，從矛盾或偽妄中可導出一切）。
  • 荒謬實例：
    • 「假若月球是綠色乳酪做成的，則清華大學位於新竹。」（真）
    • 「假若月球是綠色乳酪做成的，則清華大學不在新竹。」（真） 一個單一的虛假事實，同時使得兩個相互矛盾的後續宣稱在邏輯上皆成立。

2. 真後項悖論：Q ⊢ P → Q

  • 形式意涵：一個真命題受到任何命題的實質蘊涵。
  • 荒謬實例：
    • 「如果今天下雨，則二加二等於四。」（真）
    • 「如果今天不下雨，則二加二等於四。」（真）
    • 「如果地球是平的，則二加二等於四。」（真） 在此，前件完全喪失了作為後件「依據」、「前提」或「理由」的功能。

四、 自然語言的抗拒機制：充要條件混淆與反事實條件句

為什麼人類大腦對實質條件句如此抗拒？本資料庫指出了兩個關鍵的語言與認知機制：

1. 「充分條件」與「必要條件」的認知混淆

日常語言中，人類極易將單向充分條件（P → Q）擅自擴充解讀為雙向等值句（P ↔ Q）。

  • 在自然語言翻譯規範中，If P, then Q（P → Q）僅代表 P 充分保證 Q。
  • 但在日常心理學（如沃森選擇任務 Wason Selection Task）中，人們往往將條件句預設為「有因必有果、無因則無果」，進而犯下肯定後項謬誤（P → Q, Q ⊢ P）與否定前項謬誤（P → Q, ¬ P ⊢ ¬ Q）。

2. 反事實條件句 (Counterfactual Conditionals) 的形式崩塌

在日常對話中，存在大量「前件明知為假」的反事實修辭：

經典實例：「如果太陽從西邊升起，我就請你吃大餐！」

  • 說話者的真實語用目標：強烈斷言「我絕不會請你吃大餐」（後件為假），並藉由一個絕不可能的前件來烘托否定結論。
  • 實質條件句的災難：若翻譯為 S → D。由於「太陽從西邊升起」（S）在現實世界恆為假，依真值表，S → D 恆為真！
  • 形式系統竟然得出「這句話是真理」，與說話者用以表達強烈否定的意圖南轅北轍。這充分證明：日常語言中的反事實條件句絕不能機械對應為實質條件句。

五、 哲學家如何彌合裂縫？（Wiki 既有回應框架）

面對這一深邃鴻溝，分析哲學家開拓了兩條截然不同的搶救路線：

1. 格萊斯（H. P. Grice）的語用學救援：對話涵意 (Conversational Implicature)

保羅·格萊斯力圖捍衛實質條件句的經典定義，他主張：實質條件句的語意（Semantics）完全正確，常人感到反直覺是因為違反了「語用（Pragmatics）」中的合作原則（Cooperative Principle）。

  • 量之準則 (Maxim of Quantity)：在對話中，說話者應當提供「恰如其分且最充分」的資訊。
  • 若你明知後件 Q 為真（例如「二加二等於四」），你就應該直接斷言「二加二等於四」；如果你偏要說「若今天下雨，則二加二等於四」，你在語用上便誤導了聽眾，暗示你「唯有在下雨時才能保證該算式成立」。
  • 格萊斯的結論：悖論語句並非「假話」，而是**「在語用上極不恰當且具誤導性的真話」**。

2. C. I. 劉易斯（C. I. Lewis）的模態邏輯進路：嚴格條件句 (Strict Implication)

劉易斯認為實質條件句徹底誤解了「蘊涵（Implication）」的哲學意義。他主張真正的蘊涵必須包含必然性（Necessity）：

P ⟹ Q ≡ \Box(P → Q) ≡ ¬ \Diamond (P ∧ ¬ Q)

即：「在邏輯上不可能存在 P 為真而 Q 為假的世界」。透過引入可能世界與模態算子，徹底排除了純粹偶然性語句之間的虛假關聯。

六、 結語：形式邏輯工具的邊界與哲學省思

實質條件句不是哲學家的任意任性，而是人類為了追求符號演算的確定性、外延性（Extensionality）與機械判定性，所付出的必要代價。

  1. 形式演繹系統：追求極致的保真性、保守性與機械推理，實質條件句是維持系統運轉的最佳代數解。
  2. 自然語言溝通：追求語境相干、意圖傳遞、因果解釋與認知經濟性。

理解實質條件句的悖論，不是要否定經典命題邏輯的價值，而是要建立清晰的形式邊界意識：邏輯符號是人類理性論證的骨架，但絕非自然語言鮮活語意的全部。
