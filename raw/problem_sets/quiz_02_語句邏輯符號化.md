# 邏輯小考 (2) 解答 (語句邏輯符號化)

**日期**：2024.09.26  
**題型**：符號化翻譯

---

1. **如果我們不控制貨幣供給或不打破石油輸出國家組織的力量，我們將無法控制通貨膨脹。**
   - 符號對照：$M$ =「我們控制貨幣供給」；$O$ =「我們打破石油輸出國家組織的力量」；$I$ =「我們能夠控制通貨膨脹」
   - **解答**：$(\neg M \lor \neg O) \rightarrow \neg I$ 或 $\neg(M \land O) \rightarrow \neg I$

2. **如果小明有好的畢業成績，那麼他就會找到好工作且賺很多錢——假如他沒有追求其他目標的話。**
   - 符號對照：$G$ =「小明有好的畢業成績」；$J$ =「小明找到好工作」；$L$ =「小明賺很多錢」；$O$ =「小明追求其他目標」
   - **解答**：$G \rightarrow (\neg O \rightarrow (J \land L))$ 或 $\neg O \rightarrow (G \rightarrow (J \land L))$ 或 $(G \land \neg O) \rightarrow (J \land L)$

3. **既非下雨、也非下雪、也非天色昏暗，將會阻止你去郊遊。**
   - 符號對照：$R$ =「下雨將會阻止你去郊遊」；$S$ =「下雪將會阻止你去郊遊」；$G$ =「天色昏暗將會阻止你去郊遊」
   - **解答**：$(\neg R \land \neg S) \land \neg G$ 或 $\neg((R \lor S) \lor G)$

4. **如果我們增加稅收並消除政府浪費支出，那麼，除非有自然的大災害，否則赤字將會降低。**
   - 符號對照：$D$ =「赤字會降低」；$N$ =「有自然的大災害」；$S$ =「我們消除政府浪費支出」；$T$ =「我們增加稅收」
   - **解答**：$(T \land S) \rightarrow (N \lor D)$ 或 $(T \land S) \rightarrow (\neg N \rightarrow D)$

5. **並非小明與小華兩者都是笨蛋，但小芬卻是。**
   - 符號對照：$A$ =「小明是笨蛋」；$B$ =「小華是笨蛋」；$C$ =「小芬是笨蛋」
   - **解答**：$\neg(A \land B) \land C$ 或 $(\neg A \lor \neg B) \land C$
