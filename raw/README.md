# raw/ - 原始不可變來源層 (Raw Sources Layer)

本資料夾是本 Wiki 知識庫的**第一層（資料來源層）**。

> [!IMPORTANT]
> **規則聲明**：
> 1. 本目錄內的所有檔案均為**原始參考資料（Single Source of Truth）**。
> 2. **AI Agent 擁有唯讀權限，絕不可主動修改或刪除此處的原始檔案**。
> 3. 使用者可自由將課堂講義、作業 PDF、題目截圖等放入此處相應的子目錄中，並指令 Agent 進行「Ingest（攝取）」或「Solve（解題）」。

---

## 子目錄說明

- `lectures/`：存放教授每週發布的課堂簡報 (Slides)、手寫講義、錄音整理逐字稿。
- `readings/`：存放指定教科書章節掃描檔、哲學經典選文（如 Frege, Russell, Kripke 的邏輯篇章）。
- `problem_sets/`：存放作業題目單 (Assignments)、期中與期末考試考古題原始題卷。
- `assets/`：存放與課程相關的原始圖像檔案（如范恩圖、手繪推導樹、真值表照片）。
